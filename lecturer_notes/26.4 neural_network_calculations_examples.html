1 Initialize Hidden State

2 Compute Hidden State at t=0
RNN Formula:
h_t = tanh(W_xh × x_t + W_hh × h_{t-1} + b_h)
Substituting values:

x_0 = 0.5
h_{-1} = 0.0

h_0 = tanh(W_xh × x_0 + W_hh × h_{-1} + b_h)
    = tanh(0.5 × 0.5 + 0.8 × 0.0 + 0.1)
    = tanh(0.25 + 0.0 + 0.1)

    ≈ 0.336
✓ h_0 = 0.336
tanh function: Maps values to range [-1, 1]
tanh(x) = (e^x - e^{-x}) / (e^x + e^{-x})
3 Compute Output at t=0

y_t = W_hy × h_t + b_y
y_0 = W_hy × h_0 + b_y
    = 1.0 × 0.336 + 0.0
    = 0.336
✓ y_0 = 0.336

4 Compute Hidden State at t=1

x_1 = 0.8
h_0 = 0.336

Input Sequence (2 timesteps for simplicity):
Time t=0 Time t=1
0.5 0.8
LSTM Parameters (Simplified):
Gate Weight (W) Bias (b)
Forget Gate W_f = 0.7 b_f = 0.0
Input Gate W_i = 0.6 b_i = 0.0
Cell Candidate W_c = 0.5 b_c = 0.0
Output Gate W_o = 0.8 b_o = 0.0
Note: Real LSTM weights are matrices. Here we use scalars for clarity.
Step 1: Timestep t=0
1 Initialize States
h_{-1} = 0.0 (initial hidden state)
C_{-1} = 0.0 (initial cell state)
✓ h_{-1} = 0.0, C_{-1} = 0.0
2 Compute Forget Gate
Forget Gate Formula:
f_t = σ(W_f × [h_{t-1}, x_t] + b_f)
σ is sigmoid function: σ(x) = 1 / (1 + e^{-x}), outputs values in [0, 1]
Simplified (treating [h_{t-1}, x_t] as sum):

f_0 = σ(W_f × (h_{-1} + x_0) + b_f)
    = σ(0.7 × (0.0 + 0.5) + 0.0)
    = σ(0.35)
    = 1 / (1 + e^{-0.35})
    ≈ 0.587
✓ f_0 = 0.587 (keep ~59% of previous cell state)
3 Compute Input Gate
Input Gate Formula:
i_t = σ(W_i × [h_{t-1}, x_t] + b_i)
i_0 = σ(W_i × (h_{-1} + x_0) + b_i)
    = σ(0.6 × (0.0 + 0.5) + 0.0)
    = σ(0.30)
    ≈ 0.574
✓ i_0 = 0.574 (accept ~57% of new information)
4 Compute Cell Candidate
Cell Candidate Formula:
C̃_t = tanh(W_c × [h_{t-1}, x_t] + b_c)
C̃_0 = tanh(W_c × (h_{-1} + x_0) + b_c)
    = tanh(0.5 × (0.0 + 0.5) + 0.0)
    = tanh(0.25)
    ≈ 0.245
✓ C̃_0 = 0.245 (candidate value to add)
5 Update Cell State
Cell State Update Formula:
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t
⊙ means element-wise multiplication
C_0 = f_0 × C_{-1} + i_0 × C̃_0
    = 0.587 × 0.0 + 0.574 × 0.245
    = 0.0 + 0.141
    = 0.141
✓ C_0 = 0.141 (new cell state / long-term memory)
6 Compute Output Gate
Output Gate Formula:
o_t = σ(W_o × [h_{t-1}, x_t] + b_o)
o_0 = σ(W_o × (h_{-1} + x_0) + b_o)
    = σ(0.8 × (0.0 + 0.5) + 0.0)
    = σ(0.40)
    ≈ 0.599
✓ o_0 = 0.599 (output ~60% of cell state)
7 Compute Hidden State
Hidden State Formula:
h_t = o_t ⊙ tanh(C_t)
h_0 = o_0 × tanh(C_0)
    = 0.599 × tanh(0.141)
    = 0.599 × 0.140
    ≈ 0.084
✓ h_0 = 0.084 (hidden state / short-term output)
Step 2: Timestep t=1
8 Compute All Gates for t=1
Now we use h_0 = 0.084 and C_0 = 0.141 from previous timestep
Forget Gate:
f_1 = σ(0.7 × (0.084 + 0.8))
    = σ(0.619) ≈ 0.650

Input Gate:
i_1 = σ(0.6 × (0.084 + 0.8))
    = σ(0.530) ≈ 0.629

Cell Candidate:
C̃_1 = tanh(0.5 × (0.084 + 0.8))
    = tanh(0.442) ≈ 0.415

Cell State Update:
C_1 = f_1 × C_0 + i_1 × C̃_1
    = 0.650 × 0.141 + 0.629 × 0.415
    = 0.092 + 0.261
    = 0.353

Output Gate:
o_1 = σ(0.8 × (0.084 + 0.8))
    = σ(0.707) ≈ 0.670

Hidden State:
h_1 = o_1 × tanh(C_1)
    = 0.670 × tanh(0.353)
    = 0.670 × 0.339
    ≈ 0.227
✓ h_1 = 0.227, C_1 = 0.353

Key Differences from RNN:

1. Gated Control: LSTM uses 3 gates (forget, input, output) to control information flow
2. Cell State: Separate "memory highway" (C_t) that flows with minimal transformation
3. Selective Memory: Can selectively remember or forget information at each timestep
4. Long-term Dependencies: Cell state allows gradient to flow better through time

Gate Interpretations for t=1:
• Forget Gate (0.650): Keep 65% of previous cell state
• Input Gate (0.629): Accept 63% of new candidate information
• Output Gate (0.670): Output 67% of cell state to hidden state
Comparison: RNN vs LSTM
Aspect RNN LSTM
Hidden State Single state vector Two states: hidden (h_t) and cell (C_t)
Gates None 4 gates (forget, input, cell, output)
Parameters 3 weight matrices 8 weight matrices (4 gates × 2 weights each)
Memory Short-term only Short-term (h_t) + Long-term (C_t)
Gradient Flow Vanishes quickly Better flow through cell state
Sequence Length Struggles beyond ~10 steps Can handle 100+ steps
Computation Faster (fewer operations) Slower (4× more operations)
Use Cases Simple sequences, real-time Complex patterns, long sequences
