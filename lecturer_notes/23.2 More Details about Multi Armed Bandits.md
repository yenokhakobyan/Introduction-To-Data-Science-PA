## Introduction: Understanding the Fundamental Problem

Before we dive into the mathematics, let's establish a deep understanding of what we're trying to solve. Imagine you're a doctor with several possible treatments for a disease. Each time you treat a patient, you learn a bit more about how effective that treatment is, but you also face an ethical dilemma: should you give patients the treatment that seems best based on current knowledge (exploitation), or should you try less-tested treatments to gather more information that might help future patients (exploration)?

This is the essence of the multi-armed bandit problem, named after casino slot machines (one-armed bandits). Each "arm" represents a choice with an unknown probability of success, and we must balance learning about all options while maximizing our total reward. The mathematical beauty of this problem lies in how different algorithms approach this exploration-exploitation tradeoff.

## Part 1: Thompson Sampling - The Bayesian Approach

### Mathematical Foundation

Thompson Sampling, also known as probability matching or posterior sampling, takes a fundamentally Bayesian view of the problem. Instead of maintaining point estimates of each arm's success probability, it maintains entire probability distributions that represent our uncertainty.

Let's denote the true (unknown) success probability of arm k as θₖ. In Thompson Sampling, we maintain a posterior distribution for each θₖ, which we'll call P(θₖ|Dₖ), where Dₖ represents all the data we've observed from arm k so far.

The algorithm's elegance lies in its simplicity: at each time step, we sample from each arm's posterior distribution and play the arm with the highest sample. Mathematically:

1. For each arm k, sample θ̃ₖ ~ P(θₖ|Dₖ)
2. Select arm k* = argmax_k θ̃ₖ
3. Observe reward r from arm k*
4. Update posterior P(θₖ*|Dₖ* ∪ {r})

### The Beta-Bernoulli Model

For binary rewards (success/failure), we use the Beta-Binomial conjugacy, which makes the mathematics particularly clean. The Beta distribution is the conjugate prior for the Bernoulli distribution, meaning that if our prior is Beta and we observe Bernoulli data, our posterior is also Beta.

If we start with prior Beta(α, β) and observe s successes and f failures, our posterior is Beta(α + s, β + f).

The Beta distribution has probability density function:
```
f(x; α, β) = [Γ(α + β) / (Γ(α)Γ(β))] × x^(α-1) × (1-x)^(β-1)
```

Where Γ is the gamma function, and for positive integers n, Γ(n) = (n-1)!

The expected value of Beta(α, β) is:
```
E[X] = α / (α + β)
```

The variance is:
```
Var[X] = αβ / [(α + β)² × (α + β + 1)]
```

### Detailed Example: Online Advertisement Selection

Let's work through a concrete example where we're choosing between three different advertisement designs to maximize click-through rates.

**Initial Setup:**
- Advertisement A, B, and C with unknown click probabilities
- We start with uniform priors: Beta(1, 1) for each ad
- True probabilities (unknown to us): θₐ = 0.15, θᵦ = 0.20, θ_c = 0.18

**Round 1:**
```
Sample from posteriors:
- θ̃ₐ ~ Beta(1, 1) → sample: 0.73
- θ̃ᵦ ~ Beta(1, 1) → sample: 0.31  
- θ̃_c ~ Beta(1, 1) → sample: 0.52

Select A (highest sample)
Show Ad A → User doesn't click (reward = 0)
Update: A now has posterior Beta(1, 2)
```

Let me show you why this update makes sense. We started with Beta(1, 1), observed 0 successes and 1 failure, so our new parameters are (1 + 0, 1 + 1) = (1, 2).

**Round 2:**
```
Sample from posteriors:
- θ̃ₐ ~ Beta(1, 2) → sample: 0.22
- θ̃ᵦ ~ Beta(1, 1) → sample: 0.81
- θ̃_c ~ Beta(1, 1) → sample: 0.45

Select B (highest sample)
Show Ad B → User clicks (reward = 1)
Update: B now has posterior Beta(2, 1)
```

**After 1000 rounds:**
Let's say we have:
- Ad A: 143 clicks, 512 non-clicks → Beta(144, 513)
- Ad B: 62 clicks, 241 non-clicks → Beta(63, 242)  
- Ad C: 7 clicks, 35 non-clicks → Beta(8, 36)

Notice how the algorithm naturally focuses on the better-performing ads while still occasionally exploring. The posterior means are:
- E[θₐ] = 144/(144+513) = 0.219 (exploring most, seems promising)
- E[θᵦ] = 63/(63+242) = 0.207 (good performance)
- E[θ_c] = 8/(8+36) = 0.182 (tried least, seems worst)

### Theoretical Analysis: Why Thompson Sampling Works

The key insight is that Thompson Sampling achieves exploration through the randomness in posterior sampling. Arms with high uncertainty (few observations) have high-variance posteriors, making extreme samples more likely. This naturally encourages exploration of uncertain arms.

Mathematically, the probability of selecting arm k at time t is:

```
P(Aₜ = k) = P(θ̃ₖ > θ̃ⱼ for all j ≠ k)
```

For the two-arm case with Beta posteriors, this integral can be computed exactly:

```
P(select arm 1) = ∫₀¹ fBeta(x; α₁, β₁) × FBeta(x; α₂, β₂) dx
```

Where fBeta is the PDF and FBeta is the CDF of the Beta distribution.

### Regret Analysis

The regret at time T is defined as:
```
Regret(T) = T × max_k θₖ - Σₜ₌₁ᵀ θₐₜ
```

Thompson Sampling achieves logarithmic regret for many problem instances. Specifically, for the Bernoulli bandit with K arms, the expected regret is bounded by:

```
E[Regret(T)] ≤ Σₖ:θₖ<θ* [log(T)/KL(θₖ, θ*) + C]
```

Where θ* is the optimal arm's probability, KL is the Kullback-Leibler divergence, and C is a problem-dependent constant.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import beta
from scipy.special import betaln

def thompson_sampling_mathematical_analysis():
    """
    Deep mathematical analysis of Thompson Sampling with visualizations.
    """
    
    # Define true probabilities
    true_probs = [0.15, 0.20, 0.18]
    n_arms = len(true_probs)
    n_rounds = 5000
    
    # Initialize with uniform priors Beta(1,1)
    alpha = np.ones(n_arms)
    beta_params = np.ones(n_arms)
    
    # Track everything for analysis
    selections = []
    rewards = []
    posteriors_over_time = []
    regret_over_time = []
    cumulative_regret = 0
    
    # Optimal arm and its probability
    optimal_prob = max(true_probs)
    
    for t in range(n_rounds):
        # Sample from each posterior
        theta_samples = [
            np.random.beta(alpha[k], beta_params[k]) 
            for k in range(n_arms)
        ]
        
        # Select arm with highest sample
        selected_arm = np.argmax(theta_samples)
        selections.append(selected_arm)
        
        # Generate reward
        reward = np.random.binomial(1, true_probs[selected_arm])
        rewards.append(reward)
        
        # Update posterior
        if reward == 1:
            alpha[selected_arm] += 1
        else:
            beta_params[selected_arm] += 1
        
        # Calculate instantaneous regret
        instant_regret = optimal_prob - true_probs[selected_arm]
        cumulative_regret += instant_regret
        regret_over_time.append(cumulative_regret)
        
        # Store posterior parameters
        posteriors_over_time.append({
            'alpha': alpha.copy(),
            'beta': beta_params.copy()
        })
    
    # Theoretical analysis: Calculate exact selection probabilities
    def calculate_selection_probability(alpha1, beta1, alpha2, beta2):
        """
        Calculate exact probability that arm 1 beats arm 2.
        Uses the fact that if X ~ Beta(a1,b1) and Y ~ Beta(a2,b2),
        then P(X > Y) has a closed form.
        """
        total = 0
        for k in range(int(alpha1)):
            term = np.exp(
                betaln(alpha1 + alpha2 - k - 1, beta1 + beta2) -
                betaln(alpha2, beta2) - 
                betaln(alpha1 - k, beta1) -
                np.log(k + 1)
            )
            total += term
        return total
    
    # Visualizations
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))
    
    # Plot 1: Posterior evolution
    ax = axes[0, 0]
    x = np.linspace(0, 1, 1000)
    colors = ['blue', 'red', 'green']
    
    for k in range(n_arms):
        # Plot final posterior
        y = beta.pdf(x, alpha[k], beta_params[k])
        ax.plot(x, y, color=colors[k], linewidth=2, 
                label=f'Arm {k+1}: True θ={true_probs[k]:.2f}')
        ax.axvline(x=true_probs[k], color=colors[k], linestyle='--', alpha=0.5)
        
        # Fill area under curve
        ax.fill_between(x, y, alpha=0.2, color=colors[k])
    
    ax.set_xlabel('Success Probability θ')
    ax.set_ylabel('Posterior Density')
    ax.set_title('Final Posterior Distributions\n(Dashed lines = true values)')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 2: Selection frequency over time
    ax = axes[0, 1]
    window_size = 100
    for k in range(n_arms):
        selection_freq = []
        for i in range(window_size, n_rounds):
            freq = sum(1 for s in selections[i-window_size:i] if s == k) / window_size
            selection_freq.append(freq)
        ax.plot(range(window_size, n_rounds), selection_freq, 
                label=f'Arm {k+1}', color=colors[k])
    
    ax.set_xlabel('Round')
    ax.set_ylabel('Selection Frequency (100-round window)')
    ax.set_title('Arm Selection Frequency Over Time')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 3: Regret analysis
    ax = axes[0, 2]
    ax.plot(regret_over_time, 'b-', linewidth=2, label='Actual Regret')
    
    # Add theoretical regret bound (logarithmic)
    theoretical_bound = [
        sum((1/max(0.01, true_probs[k] - true_probs[j])) * np.log(t+1) 
            for j in range(n_arms) if j != np.argmax(true_probs))
        for t in range(n_rounds)
    ]
    ax.plot(theoretical_bound, 'r--', linewidth=2, label='Theoretical O(log T) bound')
    
    ax.set_xlabel('Round')
    ax.set_ylabel('Cumulative Regret')
    ax.set_title('Regret Growth: Actual vs Theoretical')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 4: Posterior mean convergence
    ax = axes[1, 0]
    for k in range(n_arms):
        posterior_means = [
            post['alpha'][k] / (post['alpha'][k] + post['beta'][k])
            for post in posteriors_over_time[::10]  # Sample every 10 rounds
        ]
        ax.plot(range(0, n_rounds, 10), posterior_means, 
                color=colors[k], label=f'Arm {k+1}')
        ax.axhline(y=true_probs[k], color=colors[k], linestyle='--', alpha=0.5)
    
    ax.set_xlabel('Round')
    ax.set_ylabel('Posterior Mean')
    ax.set_title('Posterior Mean Convergence\n(Dashed = true values)')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 5: Uncertainty (posterior variance) over time
    ax = axes[1, 1]
    for k in range(n_arms):
        posterior_vars = [
            (post['alpha'][k] * post['beta'][k]) / 
            ((post['alpha'][k] + post['beta'][k])**2 * 
             (post['alpha'][k] + post['beta'][k] + 1))
            for post in posteriors_over_time[::10]
        ]
        ax.plot(range(0, n_rounds, 10), posterior_vars, 
                color=colors[k], label=f'Arm {k+1}')
    
    ax.set_xlabel('Round')
    ax.set_ylabel('Posterior Variance')
    ax.set_title('Uncertainty Reduction Over Time')
    ax.legend()
    ax.grid(True, alpha=0.3)
    ax.set_yscale('log')
    
    # Plot 6: Information gain
    ax = axes[1, 2]
    
    # Calculate KL divergence from prior to current posterior
    def kl_divergence_beta(alpha1, beta1, alpha2, beta2):
        """KL divergence between two Beta distributions."""
        from scipy.special import digamma, gammaln
        
        term1 = gammaln(alpha1 + beta1) - gammaln(alpha1) - gammaln(beta1)
        term2 = gammaln(alpha2 + beta2) - gammaln(alpha2) - gammaln(beta2)
        term3 = (alpha1 - alpha2) * digamma(alpha1)
        term4 = (beta1 - beta2) * digamma(beta1)
        term5 = (alpha2 - alpha1 + beta2 - beta1) * digamma(alpha1 + beta1)
        
        return term1 - term2 + term3 + term4 + term5
    
    for k in range(n_arms):
        info_gain = [
            kl_divergence_beta(post['alpha'][k], post['beta'][k], 1, 1)
            for post in posteriors_over_time[::10]
        ]
        ax.plot(range(0, n_rounds, 10), info_gain, 
                color=colors[k], label=f'Arm {k+1}')
    
    ax.set_xlabel('Round')
    ax.set_ylabel('KL Divergence from Prior')
    ax.set_title('Information Gain (KL from Uniform Prior)')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('thompson_sampling_mathematics.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    # Print mathematical summary
    print("="*60)
    print("Thompson Sampling Mathematical Analysis")
    print("="*60)
    print(f"\nAfter {n_rounds} rounds:")
    print("\nPosterior Parameters:")
    for k in range(n_arms):
        print(f"  Arm {k+1}: Beta({alpha[k]:.0f}, {beta_params[k]:.0f})")
        mean = alpha[k] / (alpha[k] + beta_params[k])
        var = (alpha[k] * beta_params[k]) / ((alpha[k] + beta_params[k])**2 * 
                                              (alpha[k] + beta_params[k] + 1))
        print(f"    Mean: {mean:.4f} (True: {true_probs[k]:.4f})")
        print(f"    Std Dev: {np.sqrt(var):.4f}")
    
    print(f"\nTotal Regret: {cumulative_regret:.2f}")
    print(f"Average Regret per Round: {cumulative_regret/n_rounds:.4f}")
    
    # Calculate probability that each arm is best
    n_samples = 10000
    samples = np.zeros((n_samples, n_arms))
    for k in range(n_arms):
        samples[:, k] = np.random.beta(alpha[k], beta_params[k], n_samples)
    
    prob_best = np.mean(samples == samples.max(axis=1, keepdims=True), axis=0)
    print("\nProbability each arm is best:")
    for k in range(n_arms):
        print(f"  Arm {k+1}: {prob_best[k]:.4f}")
    
    return alpha, beta_params, regret_over_time

# Run the analysis
alpha_final, beta_final, regret = thompson_sampling_mathematical_analysis()
```

## Part 2: Epsilon-Greedy Algorithm - The Frequentist Approach

### Mathematical Foundation

The Epsilon-Greedy algorithm takes a frequentist view of the problem, maintaining point estimates of each arm's success rate and using a simple randomization scheme for exploration. The algorithm is defined by a single parameter ε ∈ [0, 1]:

- With probability ε: select an arm uniformly at random (exploration)
- With probability 1-ε: select the arm with highest empirical mean (exploitation)

Let's denote:
- Nₖ(t): number of times arm k has been pulled up to time t
- Sₖ(t): sum of rewards from arm k up to time t
- μ̂ₖ(t) = Sₖ(t)/Nₖ(t): empirical mean reward of arm k

The action selection rule is:
```
Aₜ = {
    argmax_k μ̂ₖ(t-1)  with probability 1-ε
    Uniform({1,...,K}) with probability ε
}
```

### Theoretical Analysis

The expected regret of ε-greedy can be decomposed into two components:

1. **Exploration regret**: When we randomly explore, we pull suboptimal arms
2. **Exploitation regret**: When we exploit, we might pull the wrong arm due to estimation error

For a fixed ε, the expected regret grows linearly with time:
```
E[Regret(T)] = ε × T × Σₖ Δₖ/K + (1-ε) × O(1)
```

Where Δₖ = θ* - θₖ is the gap between the optimal arm and arm k.

The first term (linear in T) dominates, showing that fixed ε leads to linear regret. This is why practitioners often use a decreasing ε schedule.

### Adaptive Epsilon Schedules

To achieve better theoretical guarantees, we can decrease ε over time:

**Option 1: Exponential decay**
```
εₜ = ε₀ × αᵗ, where α ∈ (0, 1)
```

**Option 2: Inverse time decay**
```
εₜ = min(1, c/t), where c > 0
```

**Option 3: Logarithmic decay (optimal for regret)**
```
εₜ = min(1, cK log(t)/t), where c > 0
```

With logarithmic decay, ε-greedy achieves logarithmic regret:
```
E[Regret(T)] = O(K log T)
```

### Detailed Example: Restaurant Recommendation System

Consider a restaurant recommendation system with 4 restaurants, each with unknown user satisfaction rates.

**Setup:**
- Restaurants A, B, C, D
- True satisfaction probabilities: θₐ = 0.7, θᵦ = 0.8, θc = 0.65, θd = 0.75
- We use ε = 0.1 (explore 10% of the time)

Let me trace through the algorithm's decision process:

**Initialization (t=0):**
All empirical means are undefined. We must pull each arm once.

**After initialization (t=4):**
Suppose we observed:
- Restaurant A: 1 visit, satisfied (μ̂ₐ = 1.0)
- Restaurant B: 1 visit, not satisfied (μ̂ᵦ = 0.0)
- Restaurant C: 1 visit, satisfied (μ̂c = 1.0)
- Restaurant D: 1 visit, satisfied (μ̂d = 1.0)

**Round 5:**
```
Generate random number r ~ Uniform(0,1)
r = 0.73

Since r > ε = 0.1, we exploit.
Current best arms: A, C, D (all tied at 1.0)
Break tie randomly → Select A
User is satisfied → Update: Nₐ = 2, Sₐ = 2, μ̂ₐ = 1.0
```

**Round 6:**
```
r = 0.03 < ε = 0.1, so we explore
Randomly select from all arms → Select B
User is satisfied → Update: Nᵦ = 2, Sᵦ = 1, μ̂ᵦ = 0.5
```

### Confidence Intervals and the Exploration Problem

A key weakness of basic ε-greedy is that it doesn't account for our confidence in the estimates. An arm pulled 1000 times with mean 0.5 is treated the same as an arm pulled twice with mean 0.5.

We can improve this by calculating confidence intervals. For Bernoulli rewards, using the normal approximation:

```
CI_k = μ̂ₖ ± z_{α/2} × √(μ̂ₖ(1-μ̂ₖ)/Nₖ)
```

For a 95% confidence interval, z_{α/2} = 1.96.

```python
def epsilon_greedy_mathematical_analysis():
    """
    Complete mathematical analysis of Epsilon-Greedy with different schedules.
    """
    
    # Setup
    true_probs = [0.7, 0.8, 0.65, 0.75]  # Restaurant satisfaction rates
    n_arms = len(true_probs)
    n_rounds = 5000
    optimal_arm = np.argmax(true_probs)
    optimal_prob = true_probs[optimal_arm]
    
    # We'll compare three epsilon schedules
    schedules = {
        'fixed': lambda t: 0.1,
        'exponential': lambda t: 0.5 * (0.995 ** t),
        'logarithmic': lambda t: min(1.0, 5 * n_arms * np.log(t + 1) / (t + 1))
    }
    
    results = {}
    
    for schedule_name, epsilon_func in schedules.items():
        # Initialize
        n_pulls = np.zeros(n_arms)
        sum_rewards = np.zeros(n_arms)
        empirical_means = np.zeros(n_arms)
        
        # Tracking
        regret_over_time = []
        epsilon_over_time = []
        selections = []
        cumulative_regret = 0
        confidence_intervals = []
        
        for t in range(n_rounds):
            # Get current epsilon
            if t < n_arms:
                # Initial exploration: pull each arm once
                action = t
            else:
                epsilon = epsilon_func(t)
                epsilon_over_time.append(epsilon)
                
                # Epsilon-greedy selection
                if np.random.random() < epsilon:
                    # Explore: random selection
                    action = np.random.choice(n_arms)
                else:
                    # Exploit: select best arm
                    # Break ties randomly
                    best_arms = np.where(empirical_means == np.max(empirical_means))[0]
                    action = np.random.choice(best_arms)
            
            selections.append(action)
            
            # Generate reward
            reward = np.random.binomial(1, true_probs[action])
            
            # Update statistics
            n_pulls[action] += 1
            sum_rewards[action] += reward
            empirical_means[action] = sum_rewards[action] / n_pulls[action]
            
            # Calculate regret
            instant_regret = optimal_prob - true_probs[action]
            cumulative_regret += instant_regret
            regret_over_time.append(cumulative_regret)
            
            # Calculate confidence intervals (after initialization)
            if t >= n_arms:
                ci = []
                for k in range(n_arms):
                    if n_pulls[k] > 0:
                        mean = empirical_means[k]
                        std_err = np.sqrt(mean * (1 - mean) / n_pulls[k])
                        ci_lower = mean - 1.96 * std_err
                        ci_upper = mean + 1.96 * std_err
                        ci.append((ci_lower, ci_upper))
                    else:
                        ci.append((0, 1))
                confidence_intervals.append(ci)
        
        results[schedule_name] = {
            'regret': regret_over_time,
            'epsilon': epsilon_over_time,
            'selections': selections,
            'final_means': empirical_means,
            'n_pulls': n_pulls,
            'confidence_intervals': confidence_intervals
        }
    
    # Visualization
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))
    
    # Plot 1: Regret comparison
    ax = axes[0, 0]
    for name, data in results.items():
        ax.plot(data['regret'], label=f'{name} ε', linewidth=2)
    ax.set_xlabel('Round')
    ax.set_ylabel('Cumulative Regret')
    ax.set_title('Regret Growth: Different ε Schedules')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 2: Epsilon decay
    ax = axes[0, 1]
    for name, data in results.items():
        if data['epsilon']:  # Skip if empty (during initialization)
            ax.plot(data['epsilon'], label=f'{name} ε', linewidth=2)
    ax.set_xlabel('Round')
    ax.set_ylabel('ε value')
    ax.set_title('Epsilon Schedules Over Time')
    ax.set_yscale('log')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 3: Arm pull distribution (final)
    ax = axes[0, 2]
    x = np.arange(n_arms)
    width = 0.25
    for i, (name, data) in enumerate(results.items()):
        ax.bar(x + i*width, data['n_pulls'], width, label=name)
    ax.set_xlabel('Arm')
    ax.set_ylabel('Number of Pulls')
    ax.set_title('Final Pull Distribution')
    ax.set_xticks(x + width)
    ax.set_xticklabels([f'Arm {i+1}\n(θ={p:.2f})' for i, p in enumerate(true_probs)])
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 4: Convergence of estimates (logarithmic schedule)
    ax = axes[1, 0]
    data = results['logarithmic']
    
    # Calculate empirical means over time
    n_pulls_time = np.zeros((n_rounds, n_arms))
    sum_rewards_time = np.zeros((n_rounds, n_arms))
    
    for t, action in enumerate(data['selections']):
        if t > 0:
            n_pulls_time[t] = n_pulls_time[t-1].copy()
            sum_rewards_time[t] = sum_rewards_time[t-1].copy()
        
        # Simulate reward for this round
        reward = np.random.binomial(1, true_probs[action])
        n_pulls_time[t, action] += 1
        sum_rewards_time[t, action] += reward
    
    # Plot empirical means
    for k in range(n_arms):
        empirical_means_time = []
        for t in range(n_rounds):
            if n_pulls_time[t, k] > 0:
                empirical_means_time.append(sum_rewards_time[t, k] / n_pulls_time[t, k])
            else:
                empirical_means_time.append(np.nan)
        
        ax.plot(empirical_means_time, label=f'Arm {k+1}', linewidth=2)
        ax.axhline(y=true_probs[k], linestyle='--', alpha=0.5)
    
    ax.set_xlabel('Round')
    ax.set_ylabel('Empirical Mean')
    ax.set_title('Convergence of Empirical Means\n(Dashed = true values)')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    # Plot 5: Confidence intervals over time
    ax = axes[1, 1]
    
    # Plot confidence intervals for the best arm at different time points
    time_points = [100, 500, 1000, 2000, 4000]
    colors = plt.cm.viridis(np.linspace(0, 1, len(time_points)))
    
    for i, t_point in enumerate(time_points):
        if t_point < len(data['confidence_intervals']):
            ci = data['confidence_intervals'][t_point]
            for k in range(n_arms):
                lower, upper = ci[k]
                ax.plot([k, k], [lower, upper], 'o-', color=colors[i],
```

## Part 3: Upper Confidence Bound (UCB) Algorithm - The Optimistic Approach

### Mathematical Foundation

The Upper Confidence Bound algorithm follows the principle of "optimism in the face of uncertainty." Instead of exploring randomly like ε-greedy or sampling from posteriors like Thompson Sampling, UCB systematically selects the arm with the highest upper confidence bound.

The core idea is to construct confidence intervals for each arm's mean reward and select the arm with the highest upper bound. This naturally balances exploration (arms with high uncertainty have wide intervals) and exploitation (arms with high empirical means have high upper bounds).

For the UCB1 algorithm, the upper confidence bound for arm k at time t is:

```
UCB_k(t) = μ̂_k(t) + √(2 ln(t) / N_k(t))
```

Where:
- μ̂_k(t) = empirical mean of arm k
- N_k(t) = number of times arm k has been pulled
- t = current time step

The action selection rule is deterministic:
```
A_t = argmax_k UCB_k(t)
```

### Theoretical Derivation

The UCB formula comes from Hoeffding's inequality. For bounded rewards in [0,1], Hoeffding's inequality states:

```
P(μ̂_k - μ_k ≥ ε) ≤ exp(-2N_k ε²)
```

We want this probability to be small, say δ_t = t^(-4). Setting:

```
exp(-2N_k ε²) = t^(-4)
```

Solving for ε:
```
ε = √(2 ln(t⁴) / N_k) = √(8 ln(t) / N_k)
```

The UCB1 algorithm uses a slightly tighter bound with coefficient 2 instead of 8, which works well in practice while maintaining theoretical guarantees.

### Regret Analysis

UCB achieves logarithmic regret. Specifically, for K arms with gaps Δ_k = θ* - θ_k:

```
E[Regret(T)] ≤ Σ_{k:Δ_k>0} [8 ln(T) / Δ_k] + (1 + π²/3) Σ_{k} Δ_k
```

This bound is asymptotically optimal up to constant factors.

### UCB Variants

**UCB1-Tuned**: Includes variance estimates
```
UCB_k(t) = μ̂_k(t) + √(ln(t) / N_k(t) × min(1/4, V_k(t)))
```
Where V_k(t) is the empirical variance plus an exploration bonus.

**UCB-V**: Explicitly uses empirical variance
```
UCB_k(t) = μ̂_k(t) + √(2σ̂²_k ln(t) / N_k(t)) + 3b ln(t) / N_k(t)
```

**Bayes-UCB**: Uses Bayesian quantiles instead of frequentist bounds
```
UCB_k(t) = Q_{1-1/(t(ln t)^c)}(θ_k | data)
```
Where Q is the quantile function of the posterior.

UCB requires each arm to be pulled at least once.

## Part 4: Comparative Analysis and Practical Insights

### When to Use Each Algorithm

Now that we understand the mathematics behind each algorithm, let's discuss when to use each approach in practice.

**Thompson Sampling** excels when:
- You have prior knowledge about the arms (can set informative priors)
- You want probabilistic guarantees about arm selection
- The problem has a natural Bayesian interpretation
- You need to quantify uncertainty about which arm is best

**Epsilon-Greedy** is preferred when:
- Simplicity is paramount
- Computational resources are limited
- You need explicit control over exploration rate
- The problem is non-stationary (can adapt ε accordingly)

**UCB** is optimal when:
- You want deterministic behavior (no randomness)
- Theoretical guarantees are important
- You have bounded rewards
- You prefer frequentist approaches

### Convergence Properties

Let's analyze how quickly each algorithm converges to the optimal arm.

For a problem with K arms and gaps Δₖ = θ* - θₖ, the convergence rates are:

**Thompson Sampling:**
- Converges at rate O(log T / Δ) for each suboptimal arm
- Posterior variance decreases as O(1/n)
- Achieves optimal regret up to constants

**Epsilon-Greedy with ε = c/t:**
- Converges at rate O(K log T)
- Suboptimal arm pulls: O(εT) = O(c log T)
- Not instance-optimal (doesn't adapt to problem difficulty)

**UCB:**
- Converges at rate O(log T / Δ²) for each suboptimal arm
- Confidence intervals shrink as O(√(log t/n))
- Nearly optimal but with slightly worse constants than Thompson Sampling

### Computational Complexity

**Per-round complexity:**
- Thompson Sampling: O(K) for sampling + O(1) for update
- Epsilon-Greedy: O(K) for finding max + O(1) for update
- UCB: O(K) for computing bounds + O(1) for update

**Memory requirements:**
- Thompson Sampling: O(K) for posterior parameters
- Epsilon-Greedy: O(K) for counts and sums
- UCB: O(K) for counts and sums

### Robustness Analysis

Let's examine how robust each algorithm is to various challenges:

**Non-stationarity (changing rewards):**
- Thompson Sampling: Can use particle filters or sliding window
- Epsilon-Greedy: Can increase ε when change detected
- UCB: Can use discounted UCB or sliding window UCB

**Heavy-tailed rewards:**
- Thompson Sampling: Use appropriate likelihood (e.g., Student-t)
- Epsilon-Greedy: Use robust mean estimators
- UCB: Use robust confidence bounds (e.g., based on median)

**Delayed feedback:**
- Thompson Sampling: Natural handling through posterior updates
- Epsilon-Greedy: Requires careful bookkeeping
- UCB: Can maintain pending rewards

```python
            sum_rewards_ucb = np.zeros(n_arms)
            regret_ucb = 0
            
            for t in range(1, n_rounds + 1):
                # Thompson Sampling
                theta_samples = [np.random.beta(alpha[k], beta_params[k]) 
                               for k in range(n_arms)]
                action_ts = np.argmax(theta_samples)
                reward_ts = np.random.binomial(1, true_probs[action_ts])
                if reward_ts:
                    alpha[action_ts] += 1
                else:
                    beta_params[action_ts] += 1
                regret_ts += optimal_reward - true_probs[action_ts]
                
                # Epsilon-Greedy
                epsilon = min(1.0, 5 * n_arms * np.log(t + 1) / (t + 1))
                if np.random.random() < epsilon or t <= n_arms:
                    action_eg = t - 1 if t <= n_arms else np.random.choice(n_arms)
                else:
                    means_eg = sum_rewards_eg / np.maximum(n_pulls_eg, 1e-10)
                    action_eg = np.argmax(means_eg)
                
                reward_eg = np.random.binomial(1, true_probs[action_eg])
                n_pulls_eg[action_eg] += 1
                sum_rewards_eg[action_eg] += reward_eg
                regret_eg += optimal_reward - true_probs[action_eg]
                
                # UCB
                ucb_values = np.zeros(n_arms)
                for k in range(n_arms):
                    if n_pulls_ucb[k] == 0:
                        ucb_values[k] = float('inf')
                    else:
                        mean_k = sum_rewards_ucb[k] / n_pulls_ucb[k]
                        ucb_values[k] = mean_k + np.sqrt(2 * np.log(t) / n_pulls_ucb[k])
                
                if np.any(np.isinf(ucb_values)):
                    action_ucb = np.where(np.isinf(ucb_values))[0][0]
                else:
                    action_ucb = np.argmax(ucb_values)
                
                reward_ucb = np.random.binomial(1, true_probs[action_ucb])
                n_pulls_ucb[action_ucb] += 1
                sum_rewards_ucb[action_ucb] += reward_ucb
                regret_ucb += optimal_reward - true_probs[action_ucb]
            
            cumulative_regrets['Thompson'].append(regret_ts)
            cumulative_regrets['Epsilon-Greedy'].append(regret_eg)
            cumulative_regrets['UCB'].append(regret_ucb)
        
        # Store summary statistics
        results_summary[config['name']] = {
            alg: {
                'mean': np.mean(cumulative_regrets[alg]),
                'std': np.std(cumulative_regrets[alg]),
                'median': np.median(cumulative_regrets[alg])
            } for alg in algorithms
        }
    
    # Display results table
    print("\n" + "="*70)
    print("COMPARATIVE ANALYSIS RESULTS")
    print("="*70)
    print(f"Based on {n_simulations} simulations of {n_rounds} rounds each")
    print("\nMean Cumulative Regret (± std):")
    
    for problem_name, results in results_summary.items():
        print(f"\n{problem_name} Problem:")
        for alg in algorithms:
            mean = results[alg]['mean']
            std = results[alg]['std']
            print(f"  {alg:15s}: {mean:7.2f} ± {std:5.2f}")
    
    return results_summary

# Run comparative analysis
```

### Final Insights and Recommendations

After this deep mathematical exploration, here are the key insights for practitioners:

1. **No Free Lunch**: No single algorithm dominates in all scenarios. The choice depends on your specific problem characteristics, constraints, and objectives.

2. **Start Simple**: If you're new to bandits, start with ε-greedy. It's simple to implement, debug, and explain to stakeholders.

3. **Graduate to UCB**: Once comfortable, UCB often provides better performance with theoretical guarantees and no random exploration.

4. **Consider Thompson for Production**: In production systems, Thompson Sampling often performs best in practice, especially with informative priors.

5. **Hybrid Approaches**: Consider combining algorithms, such as using UCB for initial exploration and Thompson Sampling for exploitation.

6. **Monitor and Adapt**: Real-world problems are rarely stationary. Build monitoring and adaptation mechanisms into your bandit algorithms.
