## 1. Introduction to A/B Testing

### What is A/B Testing?

A/B testing, also known as split testing or randomized controlled trials, is a method of comparing two versions of something to determine which performs better. In the digital world, we might test two different website designs, email subject lines, or recommendation algorithms to see which achieves better results.

The fundamental idea is simple: we randomly divide our users into two groups, show each group a different version (A or B), and measure which version performs better according to our chosen metric (conversion rate, click-through rate, revenue, etc.).

### Why Do We Need Statistical Methods?

Imagine you flip a coin 10 times and get 7 heads. Does this mean the coin is biased? Not necessarily – random variation could easily produce this result even with a fair coin. Similarly, if version B of your website shows a 5% higher conversion rate than version A after one day of testing, is B truly better, or could this difference be due to random chance?

Statistical methods help us answer this crucial question: Is the difference we observe real (statistically significant) or just random noise?

### Key Terminology

Before we dive into the methods, let's establish some fundamental terms:

- **Population**: The entire group we're interested in (all potential customers)
- **Sample**: The subset we actually test on (customers who visit during our test)
- **Null Hypothesis (H₀)**: The assumption that there's no real difference between A and B
- **Alternative Hypothesis (H₁)**: The claim that there is a real difference
- **p-value**: The probability of seeing our observed difference (or larger) if the null hypothesis is true
- **Significance Level (α)**: The threshold below which we reject the null hypothesis (commonly 0.05)
- **Statistical Power**: The probability of detecting a real difference when it exists
- **Type I Error**: Incorrectly concluding there's a difference when there isn't (false positive)
- **Type II Error**: Failing to detect a real difference (false negative)

## 2. The Frequentist Approach (Classical Statistical Testing)

### Core Philosophy

The frequentist approach treats probabilities as long-run frequencies. If we repeated our experiment many times, what proportion of times would we observe results as extreme as what we saw? This approach assumes that there is a true, fixed parameter value (like the true conversion rate), and we use our sample data to make inferences about it.

### The Z-Test for Proportions

Let's start with the most common scenario: comparing conversion rates between two groups.

#### Mathematical Foundation

Suppose we have:
- Group A: nₐ visitors, xₐ conversions, conversion rate p̂ₐ = xₐ/nₐ
- Group B: nᵦ visitors, xᵦ conversions, conversion rate p̂ᵦ = xᵦ/nᵦ

Under the null hypothesis (no difference), both groups have the same true conversion rate p. We can estimate this pooled proportion:

p̂ₚₒₒₗ = (xₐ + xᵦ)/(nₐ + nᵦ)

The standard error of the difference in proportions is:

SE = √[p̂ₚₒₒₗ(1 - p̂ₚₒₒₗ)(1/nₐ + 1/nᵦ)]

The test statistic is:

z = (p̂ᵦ - p̂ₐ)/SE

Under the null hypothesis, z follows a standard normal distribution (mean 0, standard deviation 1).

#### Detailed Example with Calculations

Let's work through a concrete example:

An e-commerce company wants to test whether a new checkout design (B) improves conversion rates compared to the current design (A).

- Version A: 5,000 visitors, 250 purchases, conversion rate = 5.0%
- Version B: 5,000 visitors, 300 purchases, conversion rate = 6.0%

Step 1: Calculate the pooled proportion
p̂ₚₒₒₗ = (250 + 300)/(5000 + 5000) = 550/10000 = 0.055

Step 2: Calculate the standard error
SE = √[0.055 × 0.945 × (1/5000 + 1/5000)]
SE = √[0.055 × 0.945 × 0.0004]
SE = √0.0000208 = 0.00456

Step 3: Calculate the z-statistic
z = (0.06 - 0.05)/0.00456 = 0.01/0.00456 = 2.19

Step 4: Find the p-value
For a two-tailed test, p-value = 2 × P(Z > 2.19) = 2 × 0.0143 = 0.0286

Since 0.0286 < 0.05, we reject the null hypothesis and conclude that version B has a significantly higher conversion rate.

#### Python Implementation

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

def frequentist_ab_test(n_a, x_a, n_b, x_b, alpha=0.05):
    """
    Perform a frequentist A/B test for proportions.
    
    Parameters:
    - n_a, n_b: sample sizes for groups A and B
    - x_a, x_b: number of conversions for groups A and B
    - alpha: significance level (default 0.05)
    
    Returns:
    - Dictionary containing test results
    """
    # Calculate conversion rates
    p_a = x_a / n_a
    p_b = x_b / n_b
    
    # Calculate pooled proportion
    p_pool = (x_a + x_b) / (n_a + n_b)
    
    # Calculate standard error
    se = np.sqrt(p_pool * (1 - p_pool) * (1/n_a + 1/n_b))
    
    # Calculate z-statistic
    z_stat = (p_b - p_a) / se
    
    # Calculate p-value (two-tailed test)
    p_value = 2 * (1 - stats.norm.cdf(abs(z_stat)))
    
    # Calculate confidence interval for the difference
    z_critical = stats.norm.ppf(1 - alpha/2)
    ci_lower = (p_b - p_a) - z_critical * se
    ci_upper = (p_b - p_a) + z_critical * se
    
    # Determine if result is significant
    is_significant = p_value < alpha
    
    return {
        'conversion_rate_a': p_a,
        'conversion_rate_b': p_b,
        'absolute_difference': p_b - p_a,
        'relative_lift': (p_b - p_a) / p_a * 100,
        'z_statistic': z_stat,
        'p_value': p_value,
        'confidence_interval': (ci_lower, ci_upper),
        'is_significant': is_significant,
        'reject_null': is_significant
    }

# Run the test with our example data
results = frequentist_ab_test(n_a=5000, x_a=250, n_b=5000, x_b=300)

print("Frequentist A/B Test Results")
print("="*40)
print(f"Conversion Rate A: {results['conversion_rate_a']:.2%}")
print(f"Conversion Rate B: {results['conversion_rate_b']:.2%}")
print(f"Absolute Difference: {results['absolute_difference']:.2%}")
print(f"Relative Lift: {results['relative_lift']:.1f}%")
print(f"Z-statistic: {results['z_statistic']:.3f}")
print(f"P-value: {results['p_value']:.4f}")
print(f"95% CI for difference: ({results['confidence_interval'][0]:.3%}, {results['confidence_interval'][1]:.3%})")
print(f"Statistically Significant: {results['is_significant']}")
```

### Sample Size Calculation

One crucial aspect of A/B testing is determining how many samples you need to detect a meaningful difference with adequate statistical power.

#### The Mathematics of Sample Size

To calculate the required sample size, we need:
- α: Significance level (typically 0.05)
- β: Type II error rate (typically 0.20, giving 80% power)
- p₁: Baseline conversion rate
- p₂: Expected conversion rate with the change (minimum detectable effect)

The formula for sample size per group is:

n = [(zₐ/₂ + zᵦ)² × (p₁(1-p₁) + p₂(1-p₂))] / (p₂ - p₁)²

Where:
- zₐ/₂ is the critical z-value for significance level α (1.96 for α=0.05)
- zᵦ is the critical z-value for power 1-β (0.84 for 80% power)

#### Python Implementation for Sample Size

```python
def calculate_sample_size(baseline_rate, minimum_detectable_effect, 
                          alpha=0.05, power=0.8):
    """
    Calculate required sample size for A/B test.
    
    Parameters:
    - baseline_rate: Current conversion rate (e.g., 0.05 for 5%)
    - minimum_detectable_effect: Relative change to detect (e.g., 0.1 for 10% lift)
    - alpha: Significance level
    - power: Statistical power (1 - β)
    
    Returns:
    - Required sample size per group
    """
    # Calculate the expected rate with the effect
    p1 = baseline_rate
    p2 = baseline_rate * (1 + minimum_detectable_effect)
    
    # Get critical z-values
    z_alpha = stats.norm.ppf(1 - alpha/2)  # Two-tailed test
    z_beta = stats.norm.ppf(power)
    
    # Calculate sample size
    numerator = (z_alpha + z_beta)**2 * (p1*(1-p1) + p2*(1-p2))
    denominator = (p2 - p1)**2
    
    n = numerator / denominator
    
    return int(np.ceil(n))

# Example: How many samples to detect a 10% lift from 5% baseline?
baseline = 0.05
mde = 0.10  # 10% relative increase

sample_size = calculate_sample_size(baseline, mde)
print(f"Required sample size per group: {sample_size:,}")
print(f"Total samples needed: {2*sample_size:,}")

# Let's see how sample size changes with different MDEs
mde_values = [0.05, 0.10, 0.15, 0.20, 0.25, 0.30]
sample_sizes = [calculate_sample_size(baseline, mde) for mde in mde_values]

plt.figure(figsize=(10, 6))
plt.plot([mde*100 for mde in mde_values], sample_sizes, 'bo-', linewidth=2)
plt.xlabel('Minimum Detectable Effect (%)', fontsize=12)
plt.ylabel('Required Sample Size per Group', fontsize=12)
plt.title('Sample Size Requirements vs Effect Size\n(5% baseline, 80% power, 5% significance)', fontsize=14)
plt.grid(True, alpha=0.3)
plt.yscale('log')
plt.show()
```

### Limitations of the Frequentist Approach

While widely used, the frequentist approach has several limitations:

1. **Fixed sample size requirement**: You must decide the sample size in advance and wait for the test to complete
2. **Multiple testing problems**: Checking results multiple times inflates Type I error rate
3. **Misinterpretation of p-values**: A p-value doesn't tell you the probability that B is better than A
4. **No early stopping**: You can't stop the test early even if results seem conclusive
5. **Binary decisions**: Only tells you "significant" or "not significant", not the probability of each hypothesis

## 3. Bootstrap Methods for A/B Testing

### Understanding the Bootstrap

The bootstrap is a powerful resampling technique that allows us to estimate the sampling distribution of almost any statistic without making strong parametric assumptions. The core idea is beautifully simple: we treat our sample as if it were the population and repeatedly resample from it (with replacement) to understand the variability in our estimates.

### Why Use Bootstrap for A/B Testing?

Bootstrap methods are particularly valuable when:
- The metric of interest doesn't follow a known distribution (e.g., revenue per user, 95th percentile load time)
- You want to calculate confidence intervals for complex metrics
- You need to avoid parametric assumptions
- You're dealing with small sample sizes where asymptotic approximations may not hold

### The Bootstrap Algorithm

1. Start with your original samples from groups A and B
2. Repeatedly (typically 10,000+ times):
   - Resample with replacement from group A (same size as original)
   - Resample with replacement from group B (same size as original)
   - Calculate the statistic of interest for each resampled group
   - Compute the difference between the groups
3. Use the distribution of differences to make inferences

### Mathematical Foundation

Let's denote:
- Original sample A: {x₁ᴬ, x₂ᴬ, ..., xₙₐᴬ}
- Original sample B: {x₁ᴮ, x₂ᴮ, ..., xₙᵦᴮ}
- Bootstrap sample from A: {x₁ᴬ*, x₂ᴬ*, ..., xₙₐᴬ*}
- Bootstrap sample from B: {x₁ᴮ*, x₂ᴮ*, ..., xₙᵦᴮ*}

For each bootstrap iteration b, we calculate:
θ̂ᵦ* = statistic(Bᵦ*) - statistic(Aᵦ*)

The bootstrap distribution of {θ̂₁*, θ̂₂*, ..., θ̂ᴮ*} approximates the sampling distribution of the difference.

### Detailed Example: Comparing Average Revenue Per User

Let's say we're testing two recommendation algorithms and want to compare average revenue per user, which often has a highly skewed distribution.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# Set random seed for reproducibility
np.random.seed(42)

# Simulate revenue data (log-normal distribution to model realistic revenue)
# Group A: Current algorithm
n_a = 1000
revenue_a = np.random.lognormal(mean=2.5, sigma=1.2, size=n_a)
revenue_a = np.round(revenue_a, 2)  # Round to cents

# Group B: New algorithm (slightly better)
n_b = 1000
revenue_b = np.random.lognormal(mean=2.6, sigma=1.2, size=n_b)
revenue_b = np.round(revenue_b, 2)

print(f"Sample Statistics:")
print(f"Group A - Mean: ${np.mean(revenue_a):.2f}, Median: ${np.median(revenue_a):.2f}")
print(f"Group B - Mean: ${np.mean(revenue_b):.2f}, Median: ${np.median(revenue_b):.2f}")
print(f"Observed difference in means: ${np.mean(revenue_b) - np.mean(revenue_a):.2f}")

def bootstrap_ab_test(sample_a, sample_b, num_bootstraps=10000, 
                      confidence_level=0.95, metric_func=np.mean):
    """
    Perform bootstrap A/B test for any metric.
    
    Parameters:
    - sample_a, sample_b: Arrays of observations from each group
    - num_bootstraps: Number of bootstrap iterations
    - confidence_level: Confidence level for interval (e.g., 0.95 for 95%)
    - metric_func: Function to calculate the metric of interest
    
    Returns:
    - Dictionary containing bootstrap results
    """
    n_a = len(sample_a)
    n_b = len(sample_b)
    
    # Calculate observed difference
    observed_metric_a = metric_func(sample_a)
    observed_metric_b = metric_func(sample_b)
    observed_diff = observed_metric_b - observed_metric_a
    
    # Perform bootstrap
    bootstrap_diffs = []
    
    for _ in range(num_bootstraps):
        # Resample with replacement
        bootstrap_a = np.random.choice(sample_a, size=n_a, replace=True)
        bootstrap_b = np.random.choice(sample_b, size=n_b, replace=True)
        
        # Calculate metrics for bootstrap samples
        metric_a = metric_func(bootstrap_a)
        metric_b = metric_func(bootstrap_b)
        
        # Store the difference
        bootstrap_diffs.append(metric_b - metric_a)
    
    bootstrap_diffs = np.array(bootstrap_diffs)
    
    # Calculate confidence interval using percentile method
    alpha = 1 - confidence_level
    ci_lower = np.percentile(bootstrap_diffs, 100 * alpha/2)
    ci_upper = np.percentile(bootstrap_diffs, 100 * (1 - alpha/2))
    
    # Calculate p-value (proportion of bootstrap samples where diff <= 0)
    # This tests if B is better than A
    p_value = np.mean(bootstrap_diffs <= 0)
    
    # Alternative p-value calculation (two-tailed)
    # How often do we see differences as extreme as observed under null?
    p_value_two_tailed = 2 * min(p_value, 1 - p_value)
    
    return {
        'observed_a': observed_metric_a,
        'observed_b': observed_metric_b,
        'observed_difference': observed_diff,
        'bootstrap_mean_diff': np.mean(bootstrap_diffs),
        'bootstrap_std_diff': np.std(bootstrap_diffs),
        'confidence_interval': (ci_lower, ci_upper),
        'p_value_one_tailed': p_value,
        'p_value_two_tailed': p_value_two_tailed,
        'bootstrap_distribution': bootstrap_diffs,
        'is_significant': ci_lower > 0 or ci_upper < 0
    }

# Run bootstrap test for mean revenue
results_mean = bootstrap_ab_test(revenue_a, revenue_b, metric_func=np.mean)

print("\nBootstrap Test Results (Mean Revenue):")
print("="*50)
print(f"Observed mean A: ${results_mean['observed_a']:.2f}")
print(f"Observed mean B: ${results_mean['observed_b']:.2f}")
print(f"Observed difference: ${results_mean['observed_difference']:.2f}")
print(f"Bootstrap mean difference: ${results_mean['bootstrap_mean_diff']:.2f}")
print(f"Bootstrap std of difference: ${results_mean['bootstrap_std_diff']:.2f}")
print(f"95% CI: (${results_mean['confidence_interval'][0]:.2f}, ${results_mean['confidence_interval'][1]:.2f})")
print(f"P-value (one-tailed, B > A): {results_mean['p_value_one_tailed']:.4f}")
print(f"P-value (two-tailed): {results_mean['p_value_two_tailed']:.4f}")
print(f"Statistically significant: {results_mean['is_significant']}")

# Visualize the bootstrap distribution
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Plot 1: Bootstrap distribution of differences
ax1 = axes[0]
ax1.hist(results_mean['bootstrap_distribution'], bins=50, density=True,

ax1.axvline(x=0, color='red', linestyle='--', linewidth=2, label='No difference')

ax1.legend()

# Plot 2: Original data distributions
ax2 = axes[1]
ax2.hist(revenue_a, bins=30, alpha=0.5, label='Group A', color='red', density=True)
ax2.hist(revenue_b, bins=30, alpha=0.5, label='Group B', color='blue', density=True)
ax2.set_xlabel('Revenue ($)', fontsize=11)
```

```python
def calculate_percentile_metric(data, percentile=95):
    """Calculate a specific percentile of the data."""
    return np.percentile(data, percentile)

def calculate_gini_coefficient(data):
    """
    Calculate the Gini coefficient (inequality measure).
    0 = perfect equality, 1 = perfect inequality
    """
    sorted_data = np.sort(data)
    n = len(data)
    cumsum = np.cumsum(sorted_data)
    return (2 * np.sum((np.arange(1, n+1)) * sorted_data)) / (n * cumsum[-1]) - (n + 1) / n
```

### Bootstrap for Ratio Metrics

Many important business metrics are ratios (e.g., revenue per user, clicks per session). The delta method can be complex for these metrics, but bootstrap handles them naturally.

```python
def bootstrap_ratio_test(numerator_a, denominator_a, numerator_b, denominator_b, 
                         num_bootstraps=10000):
    """
    Bootstrap test for ratio metrics.
    
    Example: Testing revenue per user where:
    - numerator = total revenue
    - denominator = number of users
    """
    n_a = len(numerator_a)
    n_b = len(numerator_b)
    
    # Observed ratios
    ratio_a = np.sum(numerator_a) / np.sum(denominator_a)
    ratio_b = np.sum(numerator_b) / np.sum(denominator_b)
    observed_diff = ratio_b - ratio_a
    
    bootstrap_diffs = []
    
    for _ in range(num_bootstraps):
        # Bootstrap indices
        idx_a = np.random.choice(n_a, size=n_a, replace=True)
        idx_b = np.random.choice(n_b, size=n_b, replace=True)
        
        # Calculate ratios for bootstrap samples
        ratio_boot_a = np.sum(numerator_a[idx_a]) / np.sum(denominator_a[idx_a])
        ratio_boot_b = np.sum(numerator_b[idx_b]) / np.sum(denominator_b[idx_b])
        
        bootstrap_diffs.append(ratio_boot_b - ratio_boot_a)
    
    bootstrap_diffs = np.array(bootstrap_diffs)
    
    # Calculate confidence interval
    ci_lower = np.percentile(bootstrap_diffs, 2.5)
    ci_upper = np.percentile(bootstrap_diffs, 97.5)
    
    return {
        'ratio_a': ratio_a,
        'ratio_b': ratio_b,
        'observed_difference': observed_diff,
        'confidence_interval': (ci_lower, ci_upper),
        'p_value': np.mean(bootstrap_diffs <= 0),
        'is_significant': ci_lower > 0 or ci_upper < 0
    }

# Example: Revenue per session
sessions_a = np.random.poisson(3, size=1000)  # Sessions per user in group A
revenue_per_session_a = revenue_a / np.maximum(sessions_a, 1)  # Avoid division by zero
```

## 4. The Bayesian Approach

### Philosophy of Bayesian Inference

The Bayesian approach fundamentally differs from the frequentist approach in how it interprets probability. Instead of treating parameters as fixed but unknown values, Bayesian statistics treats them as random variables with probability distributions. This allows us to:

1. Incorporate prior knowledge or beliefs
2. Update our beliefs as we observe data
3. Make probabilistic statements about parameters (e.g., "There's a 95% probability that B is better than A")
4. Make decisions under uncertainty more naturally

### Bayes' Theorem

The foundation of Bayesian inference is Bayes' theorem:

P(θ|data) = P(data|θ) × P(θ) / P(data)

Where:
- P(θ|data) is the posterior distribution (our updated belief after seeing data)
- P(data|θ) is the likelihood (probability of observing the data given the parameter)
- P(θ) is the prior distribution (our initial belief)
- P(data) is the marginal likelihood (normalization constant)

### Bayesian A/B Testing for Conversion Rates

Let's start with the most common case: comparing conversion rates using the Beta-Binomial model.

#### The Beta-Binomial Model

For conversion rates (probabilities between 0 and 1), we use:
- **Prior**: Beta(α, β) distribution for each group's conversion rate
- **Likelihood**: Binomial distribution for the observed conversions
- **Posterior**: Beta(α + conversions, β + non_conversions)

The Beta distribution is the conjugate prior for the Binomial likelihood, meaning the posterior is also a Beta distribution, which makes calculations tractable.

#### Mathematical Details

For group A:
- Prior: pₐ ~ Beta(αₐ, βₐ)
- Data: xₐ conversions out of nₐ trials
- Posterior: pₐ|data ~ Beta(αₐ + xₐ, βₐ + nₐ - xₐ)

Similarly for group B:
- Posterior: pᵦ|data ~ Beta(αᵦ + xᵦ, βᵦ + nᵦ - xᵦ)

The probability that B is better than A is:
P(pᵦ > pₐ|data) = ∫∫ I(pᵦ > pₐ) × Beta(pₐ|αₐ', βₐ') × Beta(pᵦ|αᵦ', βᵦ') dpₐ dpᵦ

Where I(·) is the indicator function and α', β' are the posterior parameters.

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

class BayesianABTest:
    """
    Bayesian A/B testing for conversion rates using Beta-Binomial model.
    """
    
    def __init__(self, prior_alpha=1, prior_beta=1):
        """
        Initialize with prior parameters.
        
        Parameters:
        - prior_alpha, prior_beta: Beta distribution parameters
          Alpha=1, Beta=1 gives uniform prior (no prior knowledge)
          Alpha=2, Beta=2 gives prior peaked at 0.5
        """
        self.prior_alpha = prior_alpha
        self.prior_beta = prior_beta
        
    def update_posterior(self, n_trials, n_successes, prior_alpha=None, prior_beta=None):
        """
        Calculate posterior Beta distribution parameters.
        
        Parameters:
        - n_trials: Number of trials (visitors)
        - n_successes: Number of successes (conversions)
        - prior_alpha, prior_beta: Optional custom priors
        
        Returns:
        - Tuple of (posterior_alpha, posterior_beta)
        """
        if prior_alpha is None:
            prior_alpha = self.prior_alpha
        if prior_beta is None:
            prior_beta = self.prior_beta
            
        posterior_alpha = prior_alpha + n_successes
        posterior_beta = prior_beta + (n_trials - n_successes)
        
        return posterior_alpha, posterior_beta
    
    def probability_b_better_than_a(self, alpha_a, beta_a, alpha_b, beta_b, 
                                    num_samples=100000):
        """
        Calculate P(B > A) using Monte Carlo simulation.
        
        Parameters:
        - alpha_a, beta_a: Posterior parameters for group A
        - alpha_b, beta_b: Posterior parameters for group B
        - num_samples: Number of Monte Carlo samples
        
        Returns:
        - Probability that B is better than A
        """
        # Draw samples from posterior distributions
        samples_a = np.random.beta(alpha_a, beta_a, num_samples)
        samples_b = np.random.beta(alpha_b, beta_b, num_samples)
        
        # Calculate probability B > A
        prob_b_better = np.mean(samples_b > samples_a)
        
        return prob_b_better
    
    def expected_loss(self, alpha_a, beta_a, alpha_b, beta_b, num_samples=100000):
        """
        Calculate expected loss from choosing each variant.
        
        Expected loss of choosing A = E[max(0, p_B - p_A)]
        Expected loss of choosing B = E[max(0, p_A - p_B)]
        
        Returns:
        - Dictionary with expected losses
        """
        samples_a = np.random.beta(alpha_a, beta_a, num_samples)
        samples_b = np.random.beta(alpha_b, beta_b, num_samples)
        
        loss_if_choose_a = np.mean(np.maximum(0, samples_b - samples_a))
        loss_if_choose_b = np.mean(np.maximum(0, samples_a - samples_b))
        
        return {
            'loss_if_choose_a': loss_if_choose_a,
            'loss_if_choose_b': loss_if_choose_b,
            'recommended_choice': 'A' if loss_if_choose_a < loss_if_choose_b else 'B'
        }
    
    def credible_interval(self, alpha, beta, credibility=0.95):
        """
        Calculate Bayesian credible interval.
        
        Parameters:
        - alpha, beta: Beta distribution parameters
        - credibility: Credibility level (e.g., 0.95 for 95% interval)
        
        Returns:
        - Tuple of (lower_bound, upper_bound)
        """
        lower = stats.beta.ppf((1 - credibility) / 2, alpha, beta)
        upper = stats.beta.ppf(1 - (1 - credibility) / 2, alpha, beta)
        
        return lower, upper
    
    def run_test(self, n_a, x_a, n_b, x_b):
        """
        Run complete Bayesian A/B test.
        
        Parameters:
        - n_a, n_b: Number of trials for groups A and B
        - x_a, x_b: Number of successes for groups A and B
        
        Returns:
        - Dictionary with complete test results
        """
        # Update posteriors
        alpha_a, beta_a = self.update_posterior(n_a, x_a)
        alpha_b, beta_b = self.update_posterior(n_b, x_b)
        
        # Calculate probability B better than A
        prob_b_better = self.probability_b_better_than_a(alpha_a, beta_a, alpha_b, beta_b)
        
        # Calculate expected losses
        losses = self.expected_loss(alpha_a, beta_a, alpha_b, beta_b)
        
        # Calculate credible intervals
        ci_a = self.credible_interval(alpha_a, beta_a)
        ci_b = self.credible_interval(alpha_b, beta_b)
        
        # Calculate posterior means
        mean_a = alpha_a / (alpha_a + beta_a)
        mean_b = alpha_b / (alpha_b + beta_b)
        
        return {
            'posterior_a': (alpha_a, beta_a),
            'posterior_b': (alpha_b, beta_b),
            'posterior_mean_a': mean_a,
            'posterior_mean_b': mean_b,
            'credible_interval_a': ci_a,
            'credible_interval_b': ci_b,
            'prob_b_better': prob_b_better,
            'prob_a_better': 1 - prob_b_better,
            'expected_loss_a': losses['loss_if_choose_a'],
            'expected_loss_b': losses['loss_if_choose_b'],
            'recommended': losses['recommended_choice']
        }
    
    def plot_posteriors(self, alpha_a, beta_a, alpha_b, beta_b, n_a, x_a, n_b, x_b):
```

### Early Stopping in Bayesian Tests

One major advantage of Bayesian A/B testing is the ability to stop early when we have sufficient confidence in the results.

```python
def bayesian_early_stopping_simulation(true_rate_a, true_rate_b, max_samples=10000,
                                      check_interval=100, confidence_threshold=0.95):
    """
    Simulate Bayesian A/B test with early stopping.
    
    Parameters:
    - true_rate_a, true_rate_b: True conversion rates
    - max_samples: Maximum samples per group
    - check_interval: How often to check stopping criteria
    - confidence_threshold: Stop when P(B > A) exceeds this
    
    Returns:
    - Dictionary with simulation results
    """
    bayesian_test = BayesianABTest()
    
    results_over_time = []
    stopped_early = False
    stopping_point = max_samples
    
    for n in range(check_interval, max_samples + 1, check_interval):
        # Simulate data up to this point
        successes_a = np.random.binomial(n, true_rate_a)
        successes_b = np.random.binomial(n, true_rate_b)
        
        # Run test
        test_results = bayesian_test.run_test(n, successes_a, n, successes_b)
        
        results_over_time.append({
            'n': n,
            'prob_b_better': test_results['prob_b_better'],
            'expected_loss_a': test_results['expected_loss_a'],
            'expected_loss_b': test_results['expected_loss_b']
        })
        
        # Check stopping criteria
        if (test_results['prob_b_better'] > confidence_threshold or 
            test_results['prob_b_better'] < (1 - confidence_threshold)):
            stopped_early = True
            stopping_point = n
            break
    
    return {
        'stopped_early': stopped_early,
        'stopping_point': stopping_point,
        'final_prob_b_better': results_over_time[-1]['prob_b_better'],
        'results_over_time': results_over_time
    }
```

### Bayesian A/B Testing for Continuous Metrics

For continuous metrics like revenue, we can use a Normal-Normal conjugate model or more flexible approaches.

```python
class BayesianContinuousABTest:
    """
    Bayesian A/B testing for continuous metrics using Normal distribution.
    """
    
    def __init__(self, prior_mean=0, prior_variance=1000):
        """
        Initialize with prior parameters for Normal distribution.
        Large prior_variance represents weak prior belief.
        """
        self.prior_mean = prior_mean
        self.prior_variance = prior_variance
    
    def update_normal_posterior(self, data, prior_mean=None, prior_variance=None, 
                               known_variance=None):
        """
        Update posterior for normal distribution.
        
        If known_variance is None, uses sample variance.
        """
        if prior_mean is None:
            prior_mean = self.prior_mean
        if prior_variance is None:
            prior_variance = self.prior_variance
            
        n = len(data)
        sample_mean = np.mean(data)
        
        if known_variance is None:
            known_variance = np.var(data, ddof=1)
        
        # Posterior parameters (conjugate update)
        posterior_variance = 1 / (1/prior_variance + n/known_variance)
        posterior_mean = posterior_variance * (prior_mean/prior_variance + 
                                              n*sample_mean/known_variance)
        
        return posterior_mean, posterior_variance
    
    def probability_b_better_continuous(self, mean_a, var_a, mean_b, var_b, 
                                       num_samples=100000):
        """
        Calculate P(B > A) for continuous metrics.
        """
        samples_a = np.random.normal(mean_a, np.sqrt(var_a), num_samples)
        samples_b = np.random.normal(mean_b, np.sqrt(var_b), num_samples)
        
        return np.mean(samples_b > samples_a)
    
    def run_continuous_test(self, data_a, data_b):
        """
        Run Bayesian test for continuous data.
        """
        # Update posteriors
        mean_a, var_a = self.update_normal_posterior(data_a)
        mean_b, var_b = self.update_normal_posterior(data_b)
        
        # Calculate probability B > A
        prob_b_better = self.probability_b_better_continuous(mean_a, var_a, mean_b, var_b)
        
        # Calculate credible intervals
        ci_a = (mean_a - 1.96*np.sqrt(var_a), mean_a + 1.96*np.sqrt(var_a))
        ci_b = (mean_b - 1.96*np.sqrt(var_b), mean_b + 1.96*np.sqrt(var_b))
        
        # Expected difference
        diff_mean = mean_b - mean_a
        diff_var = var_a + var_b
        diff_ci = (diff_mean - 1.96*np.sqrt(diff_var), diff_mean + 1.96*np.sqrt(diff_var))
        
        return {
            'posterior_mean_a': mean_a,
            'posterior_var_a': var_a,
            'posterior_mean_b': mean_b,
            'posterior_var_b': var_b,
            'credible_interval_a': ci_a,
            'credible_interval_b': ci_b,
            'difference_mean': diff_mean,
            'difference_ci': diff_ci,
            'prob_b_better': prob_b_better
        }
```

## 5. Multi-Armed Bandits

### The Exploration-Exploitation Tradeoff

Multi-armed bandits (MAB) represent a fundamentally different approach to testing. Instead of running a fixed experiment and then making a decision, MAB algorithms continuously adjust the traffic allocation to balance:

- **Exploration**: Trying different options to learn about their performance
- **Exploitation**: Directing more traffic to the currently best-performing option

This approach can reduce the "regret" (opportunity cost of not always choosing the best option) during the testing period.

### Thompson Sampling

Thompson Sampling is a Bayesian approach to the multi-armed bandit problem. For each arm (variant), we maintain a probability distribution over its true success rate. At each round, we:

1. Sample from each arm's posterior distribution
2. Choose the arm with the highest sampled value
3. Update the posterior based on the observed result

```python
class ThompsonSamplingBandit:
    """
    Thompson Sampling for multi-armed bandits with binary rewards.
    """
    
    def __init__(self, n_arms, prior_alpha=1, prior_beta=1):
        """
        Initialize Thompson Sampling bandit.
        
        Parameters:
        - n_arms: Number of arms (variants)
        - prior_alpha, prior_beta: Prior Beta distribution parameters
        """
        self.n_arms = n_arms
        self.prior_alpha = prior_alpha
        self.prior_beta = prior_beta
        
        # Initialize posterior parameters for each arm
        self.alpha = np.ones(n_arms) * prior_alpha
        self.beta = np.ones(n_arms) * prior_beta
        
        # Track performance
        self.n_trials = np.zeros(n_arms)
        self.n_successes = np.zeros(n_arms)
        self.history = []
        
    def select_arm(self):
        """
        Select an arm using Thompson Sampling.
        
        Returns:
        - Index of selected arm
        """
        # Sample from each arm's posterior
        samples = np.random.beta(self.alpha, self.beta)
        
        # Select arm with highest sample
        return np.argmax(samples)
    
    def update(self, arm, reward):
        """
        Update posterior based on observed reward.
        
        Parameters:
        - arm: Index of pulled arm
        - reward: 1 for success, 0 for failure
        """
        self.n_trials[arm] += 1
        self.n_successes[arm] += reward
        
        # Update Beta posterior
        if reward == 1:
            self.alpha[arm] += 1
        else:
            self.beta[arm] += 1
            
        # Track history
        self.history.append({
            'trial': len(self.history) + 1,
            'arm': arm,
            'reward': reward,
            'alpha': self.alpha.copy(),
            'beta': self.beta.copy()
        })
    
    def get_arm_probabilities(self):
        """
        Get current estimate of each arm's success probability.
        """
        return self.alpha / (self.alpha + self.beta)
    
    def get_selection_probabilities(self, n_simulations=10000):
        """
        Estimate probability of selecting each arm in next round.
        """
        selections = np.zeros(self.n_arms)
        
        for _ in range(n_simulations):
            samples = np.random.beta(self.alpha, self.beta)
            selections[np.argmax(samples)] += 1
            
        return selections / n_simulations

# Simulate a multi-armed bandit experiment
def simulate_thompson_sampling(true_rates, n_rounds=1000, n_arms=None):
    """
    Simulate Thompson Sampling experiment.
    
    Parameters:
    - true_rates: True success rates for each arm
    - n_rounds: Number of rounds to simulate
    - n_arms: Number of arms (inferred from true_rates if None)
    
    Returns:
    - Bandit object with history
    """
    if n_arms is None:
        n_arms = len(true_rates)
    
    bandit = ThompsonSamplingBandit(n_arms)
    
    for round_idx in range(n_rounds):
        # Select arm
        arm = bandit.select_arm()
        
        # Simulate reward
        reward = np.random.binomial(1, true_rates[arm])
        
        # Update bandit
        bandit.update(arm, reward)
    
    return bandit
```

### Epsilon-Greedy Algorithm

A simpler alternative to Thompson Sampling is the epsilon-greedy algorithm, which:
- With probability ε: explores (randomly selects an arm)
- With probability 1-ε: exploits (selects the current best arm)

```python
class EpsilonGreedyBandit:
    """
    Epsilon-greedy multi-armed bandit.
    """
    
    def __init__(self, n_arms, epsilon=0.1):
        """
        Initialize epsilon-greedy bandit.
        
        Parameters:
        - n_arms: Number of arms
        - epsilon: Exploration probability
        """
        self.n_arms = n_arms
        self.epsilon = epsilon
        
        self.n_trials = np.zeros(n_arms)
        self.n_successes = np.zeros(n_arms)
        self.estimated_rates = np.zeros(n_arms)
        self.history = []
    
    def select_arm(self):
        """Select an arm using epsilon-greedy strategy."""
        if np.random.random() < self.epsilon:
            # Explore: random selection
            return np.random.choice(self.n_arms)
        else:
            # Exploit: select best arm
            # Break ties randomly
            best_arms = np.where(self.estimated_rates == np.max(self.estimated_rates))[0]
            return np.random.choice(best_arms)
    
    def update(self, arm, reward):
        """Update estimates based on observed reward."""
        self.n_trials[arm] += 1
        self.n_successes[arm] += reward
        
        # Update estimated rate (sample mean)
        self.estimated_rates[arm] = self.n_successes[arm] / self.n_trials[arm]
        
        self.history.append({
            'trial': len(self.history) + 1,
            'arm': arm,
            'reward': reward,
            'estimated_rates': self.estimated_rates.copy()
        })

# Compare Thompson Sampling vs Epsilon-Greedy
```

### Upper Confidence Bound (UCB) Algorithm

UCB is another popular approach that selects arms based on an upper confidence bound of their estimated values.

```python
class UCBBandit:
    """
    Upper Confidence Bound (UCB1) algorithm for multi-armed bandits.
    """
    
    def __init__(self, n_arms, c=2):
        """
        Initialize UCB bandit.
        
        Parameters:
        - n_arms: Number of arms
        - c: Exploration parameter (higher = more exploration)
        """
        self.n_arms = n_arms
        self.c = c
        
        self.n_trials = np.zeros(n_arms)
        self.n_successes = np.zeros(n_arms)
        self.total_trials = 0
        self.history = []
        
        # Initialize by trying each arm once
        self.initialization_phase = True
        self.next_arm_to_try = 0
    
    def select_arm(self):
        """Select an arm using UCB strategy."""
        # Initialization: try each arm once
        if self.initialization_phase:
            arm = self.next_arm_to_try
            self.next_arm_to_try += 1
            if self.next_arm_to_try >= self.n_arms:
                self.initialization_phase = False
            return arm
        
        # Calculate UCB for each arm
        estimated_rates = self.n_successes / self.n_trials
        exploration_bonus = self.c * np.sqrt(np.log(self.total_trials) / self.n_trials)
        ucb_values = estimated_rates + exploration_bonus
        
        return np.argmax(ucb_values)
    
    def update(self, arm, reward):
        """Update estimates based on observed reward."""
        self.n_trials[arm] += 1
        self.n_successes[arm] += reward
        self.total_trials += 1
        
        self.history.append({
            'trial': len(self.history) + 1,
            'arm': arm,
            'reward': reward
        })
```

```python
class ConfidenceLibraryExample:
    """
    Example of using Spotify's Confidence library for A/B testing.
    """
    
    @staticmethod
    def run_ztest(successes_a, trials_a, successes_b, trials_b, alpha=0.05):
        """
        Run Z-test using Confidence library pattern.
        """
        # Calculate proportions
        p_a = successes_a / trials_a
        p_b = successes_b / trials_b
        
        # Pooled proportion
        p_pool = (successes_a + successes_b) / (trials_a + trials_b)
        
        # Standard error
        se = np.sqrt(p_pool * (1 - p_pool) * (1/trials_a + 1/trials_b))
        
        # Z-statistic
        z = (p_b - p_a) / se
        
        # P-value
        p_value = 2 * (1 - stats.norm.cdf(abs(z)))
        
        # Confidence interval
        ci_width = 1.96 * se
        ci = (p_b - p_a - ci_width, p_b - p_a + ci_width)
        
        return {
            'difference': p_b - p_a,
            'relative_difference': (p_b - p_a) / p_a,
            'z_statistic': z,
            'p_value': p_value,
            'confidence_interval': ci,
            'significant': p_value < alpha,
            'sample_size_a': trials_a,
            'sample_size_b': trials_b
        }
```

```python
class PlanOutStyleExperiment:
    """
    PlanOut-style experiment configuration and assignment.
    """
    
    def __init__(self, name, segments=None):
        self.name = name
        self.segments = segments or ['all']
        self.variants = {}
        self.traffic_allocation = {}
    
    def add_variant(self, name, weight):
        """Add a variant with traffic weight."""
        self.variants[name] = weight
        
    def get_assignment(self, user_id):
        """
        Deterministic assignment based on user_id.
        """
        # Hash user_id with experiment name for deterministic assignment
        import hashlib
        hash_input = f"{self.name}_{user_id}".encode()
        hash_value = int(hashlib.md5(hash_input).hexdigest(), 16)
        
        # Normalize to [0, 1)
        assignment_value = (hash_value % 10000) / 10000
        
        # Assign to variant based on weights
        cumulative = 0
        total_weight = sum(self.variants.values())
        
        for variant, weight in self.variants.items():
            cumulative += weight / total_weight
            if assignment_value < cumulative:
                return variant
        
        return list(self.variants.keys())[-1]  # Fallback to last variant
    
    def run_simulation(self, n_users=10000):
        """Simulate experiment with n users."""
        assignments = {}
        for user_id in range(n_users):
            variant = self.get_assignment(user_id)
            assignments[variant] = assignments.get(variant, 0) + 1
        
        print(f"Experiment: {self.name}")
        print(f"Assignments out of {n_users} users:")
        for variant, count in assignments.items():
            print(f"  {variant}: {count} ({count/n_users*100:.1f}%)")
        
        return assignments
```

```python
class ExperimentationFramework:
    """
    A complete experimentation framework combining multiple approaches.
    """

        self.experiments = {}

        Create a new experiment configuration.
        
        Parameters:
        - name: Experiment name
        - variants: List of variant names
        - metric_definitions: Dictionary of metric configurations

        """
        Add an observation to the experiment.
        
        Parameters:
        - experiment_name: Name of the experiment
        - variant: Variant name
        - observation: Dictionary of metric values
        """
        if experiment_name not in self.experiments:
            raise ValueError(f"Experiment {experiment_name} not found")
        
        self.experiments[experiment_name]['data'][variant].append(observation)
    
    def analyze_experiment(self, experiment_name, method='auto'):
        """
        Analyze experiment using specified method.
        
        Parameters:
        - experiment_name: Name of the experiment
        - method: 'frequentist', 'bayesian', 'bootstrap', or 'auto'
        """
        exp = self.experiments[experiment_name]
        results = {}
        
        for metric_name, metric_config in exp['metrics'].items():
            metric_type = metric_config.get('type', 'binary')
            
            if metric_type == 'binary':
                results[metric_name] = self._analyze_binary_metric(
                    exp['data'], metric_name, method
                )
            elif metric_type == 'continuous':
                results[metric_name] = self._analyze_continuous_metric(
                    exp['data'], metric_name, method
                )
            elif metric_type == 'ratio':
                results[metric_name] = self._analyze_ratio_metric(
                    exp['data'], metric_config, method
                )
        
        exp['results'] = results
        
        if self.mlflow_tracking:
            self._log_to_mlflow(experiment_name, results)
        
        return results
    
    def _analyze_binary_metric(self, data, metric_name, method):
        """Analyze binary metric (conversion, click, etc.)"""
        # Extract data for control (first variant) and treatment
        variants = list(data.keys())
        control = variants[0]
        treatment = variants[1] if len(variants) > 1 else None
        
        if not treatment:
            return {"error": "Need at least two variants"}
        
        # Calculate statistics
        control_data = [obs.get(metric_name, 0) for obs in data[control]]
        treatment_data = [obs.get(metric_name, 0) for obs in data[treatment]]
        
        n_control = len(control_data)
        n_treatment = len(treatment_data)
        x_control = sum(control_data)
        x_treatment = sum(treatment_data)
        
        if method == 'frequentist' or method == 'auto':
            return frequentist_ab_test(n_control, x_control, n_treatment, x_treatment)
        elif method == 'bayesian':
            bayes_test = BayesianABTest()
            return bayes_test.run_test(n_control, x_control, n_treatment, x_treatment)
        elif method == 'bootstrap':
            return bootstrap_ab_test(
                np.array(control_data), 
                np.array(treatment_data)
            )
    
    def _analyze_continuous_metric(self, data, metric_name, method):
        """Analyze continuous metric (revenue, time, etc.)"""
        variants = list(data.keys())
        control = variants[0]
        treatment = variants[1] if len(variants) > 1 else None
        
        if not treatment:
            return {"error": "Need at least two variants"}
        
        control_values = [obs.get(metric_name, 0) for obs in data[control]]
        treatment_values = [obs.get(metric_name, 0) for obs in data[treatment]]
        
        if method == 'bootstrap' or method == 'auto':
            return bootstrap_ab_test(
                np.array(control_values),
                np.array(treatment_values),
                metric_func=np.mean
            )
        elif method == 'bayesian':
            continuous_test = BayesianContinuousABTest()
            return continuous_test.run_continuous_test(
                np.array(control_values),
                np.array(treatment_values)
            )
    
    def _analyze_ratio_metric(self, data, metric_config, method):
        """Analyze ratio metric (e.g., revenue/user)"""
        numerator_field = metric_config['numerator']
        denominator_field = metric_config['denominator']
        
        variants = list(data.keys())
        control = variants[0]
        treatment = variants[1] if len(variants) > 1 else None
        
        control_nums = [obs.get(numerator_field, 0) for obs in data[control]]
        control_denoms = [obs.get(denominator_field, 1) for obs in data[control]]
        treatment_nums = [obs.get(numerator_field, 0) for obs in data[treatment]]
        treatment_denoms = [obs.get(denominator_field, 1) for obs in data[treatment]]
        
        return bootstrap_ratio_test(
            np.array(control_nums), np.array(control_denoms),
            np.array(treatment_nums), np.array(treatment_denoms)
        )
    
    def _log_to_mlflow(self, experiment_name, results):
        """Log results to MLflow."""
        with mlflow.start_run(run_name=experiment_name):
            mlflow.log_param("experiment_name", experiment_name)
            
            for metric_name, metric_results in results.items():
                for key, value in metric_results.items():
                    if isinstance(value, (int, float)):
                        mlflow.log_metric(f"{metric_name}_{key}", value)
    
    def get_summary(self, experiment_name):
        """Get a summary of experiment results."""
        exp = self.experiments.get(experiment_name)
        if not exp or not exp['results']:
            return "No results available"
        
        summary = []
        summary.append(f"Experiment: {experiment_name}")
        summary.append("="*50)
        
        for metric_name, results in exp['results'].items():
            summary.append(f"\nMetric: {metric_name}")
            if 'prob_b_better' in results:
                summary.append(f"  Probability treatment better: {results['prob_b_better']:.1%}")
            if 'p_value' in results:
                summary.append(f"  P-value: {results['p_value']:.4f}")
            if 'is_significant' in results:
                summary.append(f"  Statistically significant: {results['is_significant']}")
            if 'relative_lift' in results:
                summary.append(f"  Relative lift: {results['relative_lift']:.1f}%")
        
        return "\n".join(summary)
```

## 8. Summary and Practical Guidelines

### Choosing the Right Approach

The choice of A/B testing approach depends on several factors:

#### When to Use Frequentist Testing:
- You have large sample sizes (10,000+ per variant)
- The metric follows a known distribution
- Stakeholders are familiar with p-values and confidence intervals
- Regulatory requirements demand traditional statistical methods
- You need a one-time decision after fixed sample collection

#### When to Use Bootstrap Methods:
- Your metric doesn't follow a standard distribution
- You're measuring complex metrics (percentiles, ratios, Gini coefficients)
- Sample sizes are moderate (1,000-10,000)
- You want to avoid parametric assumptions
- You need confidence intervals for unusual statistics

#### When to Use Bayesian Testing:
- You want to incorporate prior knowledge
- Early stopping is important to minimize opportunity cost
- Stakeholders prefer probabilistic statements ("95% chance B is better")
- You're running many sequential tests
- You want to quantify the risk of making the wrong decision

#### When to Use Multi-Armed Bandits:
- The cost of exploration is high (losing customers, revenue)
- You have many variants to test (>2)
- You want to automatically allocate more traffic to winners
- The environment might change over time
- Real-time optimization is more important than statistical rigor

### Sample Size Guidelines

Here's a practical framework for determining sample sizes:

```python
def sample_size_calculator(baseline_rate, mde_relative, power=0.8, alpha=0.05):
    """
    Calculate required sample size for different scenarios.
    
    Parameters:
    - baseline_rate: Current metric rate (e.g., 0.05 for 5%)
    - mde_relative: Minimum detectable effect as relative change (e.g., 0.1 for 10%)
    - power: Statistical power (typically 0.8)
    - alpha: Significance level (typically 0.05)
    """
    # For proportions
    p1 = baseline_rate
    p2 = baseline_rate * (1 + mde_relative)
    
    z_alpha = stats.norm.ppf(1 - alpha/2)
    z_beta = stats.norm.ppf(power)
    
    n = ((z_alpha + z_beta)**2 * (p1*(1-p1) + p2*(1-p2))) / (p2 - p1)**2
    
    return int(np.ceil(n))
```

### Common Pitfalls and How to Avoid Them

#### 1. Peeking Problem
**Issue**: Checking results multiple times inflates Type I error rate.
**Solution**: Use Bayesian methods with proper stopping rules or sequential testing procedures.

#### 2. Multiple Testing
**Issue**: Testing multiple metrics increases false positive rate.
**Solution**: Apply Bonferroni correction or use False Discovery Rate control.

#### 3. Simpson's Paradox
**Issue**: Results can reverse when data is aggregated differently.
**Solution**: Always consider segmentation and check for confounding variables.

#### 4. Novelty Effects
**Issue**: Initial positive results fade as users adapt.
**Solution**: Run tests longer and consider time-based analysis.

#### 5. Selection Bias
**Issue**: Non-random assignment corrupts results.
**Solution**: Ensure proper randomization and check for balance in covariates.
