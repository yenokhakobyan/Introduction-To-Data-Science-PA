# Complete Data Stack Setup Guide: PostgreSQL + Airflow + dbt + Superset

## Prerequisites and Server Preparation

Before we begin building our data stack, we need to prepare our Linux server environment. This is like clearing and leveling the ground before construction.

### System Requirements
- Ubuntu 20.04+ or CentOS 7+ (this guide uses Ubuntu)
- Minimum 4GB RAM (8GB+ recommended for production)
- 50GB+ disk space
- Root or sudo access
- Python 3.8+ (we'll verify and install if needed)

### Initial Server Setup

```bash
# Update system packages - always start with a clean foundation
sudo apt update && sudo apt upgrade -y

# Install essential build tools and dependencies
sudo apt install -y curl wget git build-essential software-properties-common \
    apt-transport-https ca-certificates gnupg lsb-release python3-pip \
    python3-venv python3-dev libpq-dev

# Verify Python version (should be 3.8+)
python3 --version

# Create a dedicated user for our data stack (optional but recommended for security)
sudo useradd -m -s /bin/bash datastack
sudo usermod -aG sudo datastack
```

## Part 1: PostgreSQL Setup - Our Data Foundation

PostgreSQL will serve as both our operational database and data warehouse. Think of it as the foundation where all our data will live.

### Installation and Configuration

```bash
# Install PostgreSQL 14 (latest stable version)
sudo apt install -y postgresql postgresql-contrib

# Start and enable PostgreSQL service
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Verify installation
sudo systemctl status postgresql
```

### Database Setup and Security

```bash
# Switch to postgres user and configure
sudo -u postgres psql

-- Inside PostgreSQL shell, create databases for each service
-- This separation helps with security and organization
CREATE DATABASE airflow_db;
CREATE DATABASE superset_db;
CREATE DATABASE analytics_db;  -- This will be our main data warehouse

-- Create dedicated users with specific permissions
CREATE USER airflow_user WITH PASSWORD 'secure_airflow_password_2024';
CREATE USER superset_user WITH PASSWORD 'secure_superset_password_2024';
CREATE USER analytics_user WITH PASSWORD 'secure_analytics_password_2024';

-- Grant appropriate permissions
GRANT ALL PRIVILEGES ON DATABASE airflow_db TO airflow_user;
GRANT ALL PRIVILEGES ON DATABASE superset_db TO superset_user;
GRANT ALL PRIVILEGES ON DATABASE analytics_db TO analytics_user;

-- Exit PostgreSQL shell
\q
```

### Configure PostgreSQL for External Access

```bash
# Edit PostgreSQL configuration to allow external connections
sudo nano /etc/postgresql/14/main/postgresql.conf

# Find and modify this line (remove the # and change to *)
listen_addresses = '*'

# Edit client authentication file
sudo nano /etc/postgresql/14/main/pg_hba.conf

# Add this line at the end to allow external connections (adjust IP range as needed)
# For development: allows any IP (use with caution in production)
host    all             all             0.0.0.0/0               md5

# For production: restrict to specific IP ranges
# host    all             all             192.168.1.0/24          md5

# Restart PostgreSQL to apply changes
sudo systemctl restart postgresql

# Verify it's listening on all interfaces
sudo netstat -plunt | grep postgres
```

## Part 2: Apache Airflow Setup - Our Orchestration Engine

Airflow acts as the conductor of our data orchestra, scheduling and managing all our data workflows. We'll use a virtual environment to keep dependencies isolated.

### Python Virtual Environment Setup

```bash
# Create a dedicated directory structure
sudo mkdir -p /opt/airflow
sudo chown -R $USER:$USER /opt/airflow
cd /opt/airflow

# Create and activate virtual environment
python3 -m venv airflow_venv
source airflow_venv/bin/activate

# Upgrade pip and install wheel for better package management
pip install --upgrade pip wheel setuptools
```

### Airflow Installation and Configuration

```bash
# Set Airflow home directory
export AIRFLOW_HOME=/opt/airflow

# Install Airflow with PostgreSQL support
# We're using constraints to ensure compatible versions
AIRFLOW_VERSION=2.7.3
PYTHON_VERSION="$(python --version | cut -d " " -f 2 | cut -d "." -f 1-2)"
CONSTRAINT_URL="https://raw.githubusercontent.com/apache/airflow/constraints-${AIRFLOW_VERSION}/constraints-${PYTHON_VERSION}.txt"

pip install "apache-airflow[postgres,celery]==${AIRFLOW_VERSION}" --constraint "${CONSTRAINT_URL}"

# Initialize Airflow database
airflow db init

# Create Airflow admin user
airflow users create \
    --username admin \
    --firstname FIRST_NAME \
    --lastname LAST_NAME \
    --role Admin \
    --email admin@example.com \
    --password admin_password_2024
```

### Configure Airflow to Use PostgreSQL

```bash
# Edit Airflow configuration
nano $AIRFLOW_HOME/airflow.cfg

# Find and modify these key settings:
# Database connection (replace the sqlite line)
sql_alchemy_conn = postgresql+psycopg2://airflow_user:secure_airflow_password_2024@localhost/airflow_db

# Enable web server authentication
authenticate = True
auth_backend = airflow.api.auth.backend.basic_auth

# Configure for external access
web_server_host = 0.0.0.0
web_server_port = 8080

# Reinitialize database with PostgreSQL
airflow db init
```

### Create Airflow Service (Production Setup)


## Part 6: External Access Configuration

To access your services from external machines, you need proper network configuration.

### SSL/TLS Setup (Production Recommended)

```bash
# Install Nginx for reverse proxy and SSL termination
sudo apt install nginx certbot python3-certbot-nginx

# Create Nginx configuration for all services
sudo nano /etc/nginx/sites-available/data-stack

server {
    listen 80;
    server_name your-domain.com;

    # Airflow
    location /airflow/ {
        proxy_pass http://localhost:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Superset
    location /superset/ {
        proxy_pass http://localhost:8088/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# Enable the site
sudo ln -s /etc/nginx/sites-available/data-stack /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

# Get SSL certificate (replace with your domain)

```

## Part 7: User Management and Access Control

Adding new users to your data stack is like giving people different levels of access to different rooms in your data house. Each service has its own user management system, and we need to configure them properly to maintain security while enabling collaboration.

### PostgreSQL User Management

PostgreSQL users form the foundation of your data security. Think of these as the keys that unlock different parts of your database.

```bash
# Connect to PostgreSQL as superuser
sudo -u postgres psql

-- Create different types of users based on their needs
-- Read-only analyst (can only view data, perfect for data analysts)
CREATE USER analyst_user WITH PASSWORD 'secure_analyst_password_2024';

-- Grant read access to analytics database
GRANT CONNECT ON DATABASE analytics_db TO analyst_user;
\c analytics_db
GRANT USAGE ON SCHEMA public TO analyst_user;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO analyst_user;
-- This ensures they get read access to future tables too
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO analyst_user;

-- Data engineer user (can read, write, and create objects)
CREATE USER engineer_user WITH PASSWORD 'secure_engineer_password_2024';
GRANT CONNECT ON DATABASE analytics_db TO engineer_user;
\c analytics_db
GRANT USAGE, CREATE ON SCHEMA public TO engineer_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO engineer_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT, INSERT, UPDATE, DELETE ON TABLES TO engineer_user;

-- Create a dedicated schema for each team or project
CREATE SCHEMA marketing_analytics;
CREATE SCHEMA sales_analytics;

-- Grant schema-specific permissions
GRANT USAGE, CREATE ON SCHEMA marketing_analytics TO engineer_user;
GRANT USAGE ON SCHEMA marketing_analytics TO analyst_user;

-- Exit PostgreSQL
\q
```

Understanding PostgreSQL permissions is crucial because they cascade through your entire data stack. When you grant someone access to a database, you are essentially giving them permission to see and potentially modify the data that feeds into your dbt models and Superset dashboards.

### Airflow User Management

Airflow uses role-based access control, which means you assign users to roles, and roles have specific permissions. This is similar to how companies assign job titles that come with certain responsibilities.

```bash
# Activate Airflow environment
source /opt/airflow/airflow_venv/bin/activate
export AIRFLOW_HOME=/opt/airflow

# Create different types of users
# Viewer role - can see DAGs and task instances but cannot trigger runs
airflow users create \
    --username data_analyst \
    --firstname Data \
    --lastname Analyst \
    --role Viewer \
    --email analyst@company.com \
    --password analyst_password_2024

# Op role - can trigger DAG runs and mark tasks as success/failed
airflow users create \
    --username data_engineer \
    --firstname Data \
    --lastname Engineer \
    --role Op \
    --email engineer@company.com \
    --password engineer_password_2024

# User role - has Op permissions plus can edit connections and variables
airflow users create \
    --username senior_engineer \
    --firstname Senior \
    --lastname Engineer \
    --role User \
    --email senior_engineer@company.com \
    --password senior_password_2024

# List all users to verify
airflow users list

# You can also modify existing users
# airflow users delete --username username_to_delete
# airflow users add-role --username existing_user --role Op
```

The beauty of Airflow's role system is that it prevents accidental damage. A data analyst can monitor pipeline health and investigate issues, but they cannot accidentally trigger a full data refresh that might overwrite production data.

### Database Connection Security for Different Users

Each user type needs different database access patterns. Here is how to set up secure connections that match their roles.

```bash
# Create read-only connection strings for different user types
# These go in Superset's database connections

# For analysts (read-only access to specific schemas)
# Connection String: postgresql+psycopg2://analyst_user:secure_analyst_password_2024@localhost/analytics_db

# For dashboard creators (broader read access)
# Connection String: postgresql+psycopg2://engineer_user:secure_engineer_password_2024@localhost/analytics_db

# You can also create database-specific users
sudo -u postgres psql

-- Marketing-specific user
CREATE USER marketing_analyst WITH PASSWORD 'marketing_password_2024';
GRANT CONNECT ON DATABASE analytics_db TO marketing_analyst;
\c analytics_db
GRANT USAGE ON SCHEMA marketing_analytics TO marketing_analyst;
GRANT SELECT ON ALL TABLES IN SCHEMA marketing_analytics TO marketing_analyst;

-- Sales-specific user  
CREATE USER sales_analyst WITH PASSWORD 'sales_password_2024';
GRANT CONNECT ON DATABASE analytics_db TO sales_analyst;
GRANT USAGE ON SCHEMA sales_analytics TO sales_analyst;
GRANT SELECT ON ALL TABLES IN SCHEMA sales_analytics TO sales_analyst;

\q
```

This approach follows the principle of least privilege - each user gets exactly the access they need, nothing more. If your marketing analyst's credentials were somehow compromised, they could not access sales data or modify anything.

### Row-Level Security (Advanced)

For organizations with strict data governance requirements, PostgreSQL offers row-level security, which lets you control which rows different users can see.

```bash
# Connect to PostgreSQL
sudo -u postgres psql
\c analytics_db

-- Enable row-level security on a table
ALTER TABLE customer_data ENABLE ROW LEVEL SECURITY;

-- Create policies that restrict access
-- Marketing users can only see customers from their campaigns
CREATE POLICY marketing_customers ON customer_data
    FOR ALL TO marketing_analyst
    USING (campaign_source = 'marketing');

-- Sales users can only see customers in their territory
CREATE POLICY sales_territory ON customer_data  
    FOR ALL TO sales_analyst
    USING (sales_territory = current_setting('app.current_territory'));

\q
```

Row-level security is like having smart locks on your data - the same table appears different to different users based on their role and context.

### Monitoring User Activity

```python
import pandas as pd
import numpy as np
from datetime import datetime, timedelta
import random
import psycopg2
from sqlalchemy import create_engine
import argparse
import logging
from faker import Faker

# Set up logging so we can monitor our data generation process
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

class ECommerceDataGenerator:
    """
    This class generates realistic e-commerce data that mimics patterns you'd see
    in real business data. We're creating customers, products, and orders with
    realistic relationships and distributions.
    """
    
    def __init__(self, num_customers=1000, num_products=200, num_orders=5000):
        self.fake = Faker()
        self.num_customers = num_customers
        self.num_products = num_products  
        self.num_orders = num_orders
        
        # These lists help us create realistic product categories and names
        self.categories = ['Electronics', 'Clothing', 'Home & Garden', 'Sports', 'Books', 'Beauty']
        self.product_prefixes = {
            'Electronics': ['Smart', 'Wireless', 'Digital', 'HD', 'Pro'],
            'Clothing': ['Premium', 'Classic', 'Trendy', 'Comfort', 'Designer'],
            'Home & Garden': ['Luxury', 'Modern', 'Vintage', 'Eco', 'Deluxe'],
            'Sports': ['Athletic', 'Professional', 'Outdoor', 'Performance', 'Training'],
            'Books': ['Complete', 'Essential', 'Advanced', 'Beginner', 'Ultimate'],
            'Beauty': ['Natural', 'Organic', 'Premium', 'Professional', 'Anti-aging']
        }
        
        # Price ranges that make sense for each category
        self.price_ranges = {
            'Electronics': (50, 2000),
            'Clothing': (20, 300),
            'Home & Garden': (25, 800),
            'Sports': (15, 500),
            'Books': (10, 80),
            'Beauty': (15, 200)
        }

    def generate_customers(self):
        """
        Generate a realistic customer base with geographic distribution
        that mirrors real business patterns. Notice how we're creating
        a foundation that other tables will reference.
        """
        logger.info("Generating customer data...")
        
        customers = []
        for i in range(self.num_customers):
            # Create realistic customer profiles with proper demographics
            customer = {
                'customer_id': i + 1,
                'first_name': self.fake.first_name(),
                'last_name': self.fake.last_name(),
                'email': self.fake.email(),
                'phone': self.fake.phone_number(),
                'address': self.fake.street_address(),
                'city': self.fake.city(),
                'state': self.fake.state(),
                'postal_code': self.fake.postcode(),
                'country': 'USA',  # Simplifying for this example
                'registration_date': self.fake.date_between(start_date='-2y', end_date='today'),
                'date_of_birth': self.fake.date_of_birth(minimum_age=18, maximum_age=80),
                # Customer segments that will drive different buying behaviors
                'customer_segment': random.choices(
                    ['Premium', 'Regular', 'Budget'], 
                    weights=[20, 60, 20]
                )[0],
                'created_at': datetime.now(),
                'updated_at': datetime.now()
            }
            customers.append(customer)
            
        return pd.DataFrame(customers)

    def generate_products(self):
        """
        Create a product catalog that reflects real inventory patterns.
        Notice how we're establishing relationships between categories,
        names, and prices that make business sense.
        """
        logger.info("Generating product catalog...")
        
        products = []
        for i in range(self.num_products):
            category = random.choice(self.categories)
            prefix = random.choice(self.product_prefixes[category])
            base_name = self.fake.word().title()
            
            # Create realistic pricing within category ranges
            min_price, max_price = self.price_ranges[category]
            base_price = round(random.uniform(min_price, max_price), 2)
            
            product = {
                'product_id': i + 1,
                'product_name': f"{prefix} {base_name}",
                'category': category,
                'subcategory': f"{category} - {random.choice(['Premium', 'Standard', 'Budget'])}",
                'brand': self.fake.company(),
                'price': base_price,
                # Cost margins that reflect real business economics
                'cost': round(base_price * random.uniform(0.4, 0.7), 2),
                'weight_kg': round(random.uniform(0.1, 20.0), 2),
                'stock_quantity': random.randint(0, 1000),
                'description': self.fake.text(max_nb_chars=200),
                'created_at': datetime.now(),
                'updated_at': datetime.now()
            }
            products.append(product)
            
        return pd.DataFrame(products)

    def generate_orders(self, customers_df, products_df):
        """
        Generate order data that reflects realistic customer behavior patterns.
        This is where the business logic really comes into play - different
        customer segments behave differently, seasonal patterns matter, etc.
        """
        logger.info("Generating order transactions...")
        
        orders = []
        order_items = []
        order_id = 1
        
        # Define customer behavior patterns based on segments
        segment_behavior = {
            'Premium': {'avg_order_value': 250, 'items_per_order': (2, 8), 'frequency': 0.8},
            'Regular': {'avg_order_value': 120, 'items_per_order': (1, 4), 'frequency': 0.5},
            'Budget': {'avg_order_value': 60, 'items_per_order': (1, 2), 'frequency': 0.3}
        }
        
        for _, customer in customers_df.iterrows():
            segment = customer['customer_segment']
            behavior = segment_behavior[segment]
            
            # Determine how many orders this customer will have
            # Premium customers order more frequently
            orders_count = int(np.random.poisson(self.num_orders / self.num_customers * behavior['frequency']))
            
            for _ in range(max(1, orders_count)):
                order_date = self.fake.date_between(
                    start_date=customer['registration_date'], 
                    end_date='today'
                )
                
                # Determine number of items in this order
                min_items, max_items = behavior['items_per_order']
                items_count = random.randint(min_items, max_items)
                
                # Select products for this order (avoiding duplicates)
                order_products = products_df.sample(n=min(items_count, len(products_df)))
                
                order_total = 0
                order_items_list = []
                
                for _, product in order_products.iterrows():
                    # Quantity based on customer segment and product price
                    if segment == 'Premium':
                        quantity = random.randint(1, 3)
                    else:
                        quantity = 1 if random.random() < 0.8 else 2
                    
                    item_total = product['price'] * quantity
                    order_total += item_total
                    
                    order_item = {
                        'order_item_id': len(order_items) + len(order_items_list) + 1,
                        'order_id': order_id,
                        'product_id': product['product_id'],
                        'quantity': quantity,
                        'unit_price': product['price'],
                        'total_price': item_total,
                        'created_at': datetime.combine(order_date, datetime.min.time())
                    }
                    order_items_list.append(order_item)
                
                # Create the main order record
                order = {
                    'order_id': order_id,
                    'customer_id': customer['customer_id'],
                    'order_date': order_date,
                    'order_status': random.choices(
                        ['completed', 'pending', 'shipped', 'cancelled'], 
                        weights=[70, 10, 15, 5]
                    )[0],
                    'total_amount': round(order_total, 2),
                    'shipping_cost': round(random.uniform(5, 25), 2) if order_total < 100 else 0,
                    'tax_amount': round(order_total * 0.08, 2),  # 8% tax rate
                    'payment_method': random.choice(['credit_card', 'debit_card', 'paypal', 'bank_transfer']),
                    'shipping_address': customer['address'],
                    'created_at': datetime.combine(order_date, datetime.min.time()),
                    'updated_at': datetime.now()
                }
                
                orders.append(order)
                order_items.extend(order_items_list)
                order_id += 1
        
        return pd.DataFrame(orders), pd.DataFrame(order_items)

def load_data_to_postgres(customers_df, products_df, orders_df, order_items_df):
    """
    Load our generated data into PostgreSQL. This function demonstrates
    proper database loading patterns including error handling and
    transaction management.
    """
    # Database connection string - in production, use environment variables
    connection_string = "postgresql+psycopg2://analytics_user:secure_analytics_password_2024@localhost/analytics_db"
    
    try:
        # Create database engine
        engine = create_engine(connection_string)
        
        logger.info("Loading data to PostgreSQL...")
        
        # Load data in the correct order due to foreign key relationships
        # Customers first (no dependencies)
        customers_df.to_sql('customers', engine, if_exists='replace', index=False, method='multi')
        logger.info(f"Loaded {len(customers_df)} customers")
        
        # Products second (no dependencies)
        products_df.to_sql('products', engine, if_exists='replace', index=False, method='multi')
        logger.info(f"Loaded {len(products_df)} products")
        
        # Orders third (depends on customers)
        orders_df.to_sql('orders', engine, if_exists='replace', index=False, method='multi')
        logger.info(f"Loaded {len(orders_df)} orders")
        
        # Order items last (depends on orders and products)
        order_items_df.to_sql('order_items', engine, if_exists='replace', index=False, method='multi')
        logger.info(f"Loaded {len(order_items_df)} order items")
        
        logger.info("Data loading completed successfully!")
        
    except Exception as e:
        logger.error(f"Error loading data to PostgreSQL: {str(e)}")
        raise

def main():
    """
    Main function that orchestrates the entire data generation process.
    This pattern makes it easy to run from command line or from Airflow.
    """
    parser = argparse.ArgumentParser(description='Generate sample e-commerce data')
    parser.add_argument('--customers', type=int, default=1000, help='Number of customers to generate')
    parser.add_argument('--products', type=int, default=200, help='Number of products to generate')
    parser.add_argument('--orders', type=int, default=5000, help='Number of orders to generate')
    parser.add_argument('--csv-output', action='store_true', help='Also save data as CSV files')
    
    args = parser.parse_args()
    
    # Initialize the data generator
    generator = ECommerceDataGenerator(
        num_customers=args.customers,
        num_products=args.products, 
        num_orders=args.orders
    )
    
    # Generate all data
    logger.info("Starting data generation process...")
    customers_df = generator.generate_customers()
    products_df = generator.generate_products()  
    orders_df, order_items_df = generator.generate_orders(customers_df, products_df)
    
    # Optionally save to CSV for inspection or backup
    if args.csv_output:
        logger.info("Saving CSV files...")
        customers_df.to_csv('/opt/airflow/data/customers.csv', index=False)
        products_df.to_csv('/opt/airflow/data/products.csv', index=False)
        orders_df.to_csv('/opt/airflow/data/orders.csv', index=False)
        order_items_df.to_csv('/opt/airflow/data/order_items.csv', index=False)
    
    # Load to PostgreSQL
    load_data_to_postgres(customers_df, products_df, orders_df, order_items_df)
    
    logger.info("Data generation pipeline completed successfully!")

if __name__ == "__main__":
    main()
```

```sql
            ((total_revenue - lag(total_revenue) over (order by month_date)) 
             / lag(total_revenue) over (order by month_date) * 100), 2
```

```python
import pandas as pd
import numpy as np
from sqlalchemy import create_engine
import argparse
import logging
import os
from pathlib import Path

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

class CSVDataLoader:
    """
    This class loads CSV files into PostgreSQL with proper data type handling
    and validation. It's designed to handle real business data that might have
    quality issues or inconsistent formats.
    """
    
    def __init__(self, connection_string):
        self.engine = create_engine(connection_string)
        
    def clean_and_validate_customers(self, df):
        """Clean customer data and handle common data quality issues"""
        logger.info("Cleaning customer data...")
        
        # Remove duplicates based on email (assuming email should be unique)
        initial_count = len(df)
        df = df.drop_duplicates(subset=['email'], keep='first')
        if len(df) < initial_count:
            logger.warning(f"Removed {initial_count - len(df)} duplicate customers")
        
        # Clean email addresses
        df['email'] = df['email'].str.lower().str.strip()
        
        # Handle missing names
        df['first_name'] = df['first_name'].fillna('Unknown')
        df['last_name'] = df['last_name'].fillna('Unknown')
        
        # Validate and clean phone numbers (basic cleaning)
        df['phone'] = df['phone'].astype(str).str.replace(r'[^\d\-\(\)\s\+]', '', regex=True)
        
        # Ensure required fields are not null
        required_fields = ['customer_id', 'email', 'first_name', 'last_name']
        for field in required_fields:
            if df[field].isnull().any():
                logger.error(f"Required field {field} has null values")
                raise ValueError(f"Null values found in required field: {field}")
        
        logger.info(f"Customer data cleaned: {len(df)} records ready for loading")
        return df
    
    def clean_and_validate_products(self, df):
        """Clean product data and handle pricing issues"""
        logger.info("Cleaning product data...")
        
        # Remove products with invalid prices
        initial_count = len(df)
        df = df[(df['price'] > 0) & (df['cost'] >= 0)]
        if len(df) < initial_count:
            logger.warning(f"Removed {initial_count - len(df)} products with invalid pricing")
        
        # Ensure cost is not higher than price (basic business rule)
        df['cost'] = df.apply(lambda row: min(row['cost'], row['price'] * 0.95), axis=1)
        
        # Clean product names
        df['product_name'] = df['product_name'].str.strip()
        
        # Handle missing categories
        df['category'] = df['category'].fillna('Uncategorized')
        
        logger.info(f"Product data cleaned: {len(df)} records ready for loading")
        return df
    
    def clean_and_validate_orders(self, df, customers_df):
        """Clean order data and validate relationships"""
        logger.info("Cleaning order data...")
        
        # Convert order_date to datetime if it's not already
        df['order_date'] = pd.to_datetime(df['order_date'])
        
        # Validate that all customers exist
        valid_customers = set(customers_df['customer_id'])
        invalid_orders = df[~df['customer_id'].isin(valid_customers)]
        if not invalid_orders.empty:
            logger.warning(f"Found {len(invalid_orders)} orders with invalid customer_ids")
            df = df[df['customer_id'].isin(valid_customers)]
        
        # Ensure positive amounts
        df = df[df['total_amount'] > 0]
        
        # Clean order status
        valid_statuses = ['completed', 'pending', 'shipped', 'cancelled']
        df['order_status'] = df['order_status'].str.lower()
        df = df[df['order_status'].isin(valid_statuses)]
        
        logger.info(f"Order data cleaned: {len(df)} records ready for loading")
        return df
    
    def load_csv_files(self, csv_directory, table_mappings=None):
        """
        Load CSV files from a directory into PostgreSQL tables.
        
        table_mappings: dict mapping CSV filename (without extension) to table name
        If None, assumes CSV filename matches table name
        """
        if table_mappings is None:
            table_mappings = {
                'customers': 'customers',
                'products': 'products', 
                'orders': 'orders',
                'order_items': 'order_items'
            }
        
        csv_path = Path(csv_directory)
        loaded_data = {}
        
        # Load customers first (no dependencies)
        if 'customers' in table_mappings:
            customers_file = csv_path / f"customers.csv"
            if customers_file.exists():
                logger.info(f"Loading customers from {customers_file}")
                customers_df = pd.read_csv(customers_file)
                customers_df = self.clean_and_validate_customers(customers_df)
                customers_df.to_sql('customers', self.engine, if_exists='replace', index=False)
                loaded_data['customers'] = customers_df
                logger.info(f"Loaded {len(customers_df)} customers")
            else:
                logger.error(f"Customer file not found: {customers_file}")
                raise FileNotFoundError(f"Required file not found: {customers_file}")
        
        # Load products (no dependencies)
        if 'products' in table_mappings:
            products_file = csv_path / f"products.csv"
            if products_file.exists():
                logger.info(f"Loading products from {products_file}")
                products_df = pd.read_csv(products_file)
                products_df = self.clean_and_validate_products(products_df)
                products_df.to_sql('products', self.engine, if_exists='replace', index=False)
                loaded_data['products'] = products_df
                logger.info(f"Loaded {len(products_df)} products")
            else:
                logger.error(f"Products file not found: {products_file}")
                raise FileNotFoundError(f"Required file not found: {products_file}")
        
        # Load orders (depends on customers)
        if 'orders' in table_mappings:
            orders_file = csv_path / f"orders.csv"
            if orders_file.exists():
                logger.info(f"Loading orders from {orders_file}")
                orders_df = pd.read_csv(orders_file)
                orders_df = self.clean_and_validate_orders(orders_df, loaded_data['customers'])
                orders_df.to_sql('orders', self.engine, if_exists='replace', index=False)
                loaded_data['orders'] = orders_df
                logger.info(f"Loaded {len(orders_df)} orders")
            else:
                logger.error(f"Orders file not found: {orders_file}")
                raise FileNotFoundError(f"Required file not found: {orders_file}")
        
        # Load order items (depends on orders and products)
        if 'order_items' in table_mappings:
            order_items_file = csv_path / f"order_items.csv"
            if order_items_file.exists():
                logger.info(f"Loading order items from {order_items_file}")
                order_items_df = pd.read_csv(order_items_file)
                
                # Validate relationships
                valid_orders = set(loaded_data['orders']['order_id'])
                valid_products = set(loaded_data['products']['product_id'])
                
                order_items_df = order_items_df[
                    order_items_df['order_id'].isin(valid_orders) &
                    order_items_df['product_id'].isin(valid_products)
                ]
                
                order_items_df.to_sql('order_items', self.engine, if_exists='replace', index=False)
                loaded_data['order_items'] = order_items_df
                logger.info(f"Loaded {len(order_items_df)} order items")
            else:
                logger.error(f"Order items file not found: {order_items_file}")
                raise FileNotFoundError(f"Required file not found: {order_items_file}")
        
        logger.info("All CSV files loaded successfully!")
        return loaded_data
```

```sql
-- Customer cohort analysis for retention insights
CREATE VIEW customer_cohort_analysis AS
WITH customer_cohorts AS (
    SELECT 
        customer_id,
        DATE_TRUNC('month', first_order_date) as cohort_month,
        DATE_TRUNC('month', order_date) as order_month
    FROM (
        SELECT 
            customer_id,
            order_date,
            MIN(order_date) OVER (PARTITION BY customer_id) as first_order_date
        FROM fact_order_items
    ) cohort_base
),
cohort_data AS (
    SELECT
        cohort_month,
        order_month,
        COUNT(DISTINCT customer_id) as customers,
        EXTRACT(MONTH FROM AGE(order_month, cohort_month)) as period_number
    FROM customer_cohorts
    GROUP BY cohort_month, order_month
)
SELECT
    cohort_month,
    period_number,
    customers,
    FIRST_VALUE(customers) OVER (PARTITION BY cohort_month ORDER BY period_number) as cohort_size,
    ROUND(
        customers::NUMERIC / FIRST_VALUE(customers) OVER (PARTITION BY cohort_month ORDER BY period_number) * 100, 
        2
    ) as retention_rate
FROM cohort_data
ORDER BY cohort_month, period_number;

-- Market basket analysis for cross-selling opportunities
CREATE VIEW market_basket_analysis AS
WITH order_products AS (
    SELECT 
        o.order_id,
        p.product_name,
        p.category,
        oi.quantity
    FROM fact_order_items oi
    JOIN stg_products p ON oi.product_id = p.product_id
    JOIN stg_orders o ON oi.order_id = o.order_id
    WHERE o.order_status = 'completed'
),
product_pairs AS (
    SELECT 
        op1.product_name as product_a,
        op2.product_name as product_b,
        COUNT(*) as frequency
    FROM order_products op1
    JOIN order_products op2 ON op1.order_id = op2.order_id
    WHERE op1.product_name < op2.product_name  -- Avoid duplicates and self-pairs
    GROUP BY op1.product_name, op2.product_name
    HAVING COUNT(*) >= 5  -- Only pairs that occur at least 5 times
),
product_totals AS (
    SELECT 
        product_name,
        COUNT(DISTINCT order_id) as total_orders
    FROM order_products
    GROUP BY product_name
)
SELECT 
    pp.product_a,
    pp.product_b,
    pp.frequency,
    pt1.total_orders as product_a_total,
    pt2.total_orders as product_b_total,
    ROUND(pp.frequency::NUMERIC / LEAST(pt1.total_orders, pt2.total_orders) * 100, 2) as confidence_score
FROM product_pairs pp
JOIN product_totals pt1 ON pp.product_a = pt1.product_name
JOIN product_totals pt2 ON pp.product_b = pt2.product_name
ORDER BY confidence_score DESC, frequency DESC
LIMIT 50;

-- Customer RFM analysis (Recency, Frequency, Monetary)
CREATE VIEW customer_rfm_analysis AS
WITH rfm_calc AS (
    SELECT 
        customer_id,
        -- Recency: days since last order
        EXTRACT(DAY FROM CURRENT_DATE - MAX(order_date)) as recency_days,
        -- Frequency: number of orders
        COUNT(DISTINCT order_id) as frequency,
        -- Monetary: total revenue
        SUM(revenue) as monetary
    FROM fact_order_items
    GROUP BY customer_id
),
rfm_scores AS (
    SELECT
        customer_id,
        recency_days,
        frequency,
        monetary,
        -- Create quintile scores (1-5, where 5 is best)
        NTILE(5) OVER (ORDER BY recency_days DESC) as recency_score,  -- Lower recency is better
        NTILE(5) OVER (ORDER BY frequency ASC) as frequency_score,
        NTILE(5) OVER (ORDER BY monetary ASC) as monetary_score
    FROM rfm_calc
)
SELECT
    customer_id,
    recency_days,
    frequency,
    monetary,
    recency_score,
    frequency_score, 
    monetary_score,
    CONCAT(recency_score, frequency_score, monetary_score) as rfm_segment,
    CASE 
        WHEN recency_score >= 4 AND frequency_score >= 4 AND monetary_score >= 4 THEN 'Champions'
        WHEN recency_score >= 3 AND frequency_score >= 3 AND monetary_score >= 3 THEN 'Loyal Customers'
        WHEN recency_score >= 4 AND frequency_score <= 2 THEN 'New Customers'
        WHEN recency_score <= 2 AND frequency_score >= 3 THEN 'At Risk'
        WHEN recency_score <= 2 AND frequency_score <= 2 THEN 'Lost Customers'
        ELSE 'Regular Customers'
    END as customer_segment_rfm
FROM rfm_scores
ORDER BY monetary DESC;
```

```python
import psycopg2
import pandas as pd
from datetime import datetime, timedelta
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

class PipelineMonitor:
    """
    Monitor pipeline health and send alerts when issues are detected.
    This is crucial for production data pipelines.
    """
    
    def __init__(self, db_connection_string):
        self.connection_string = db_connection_string
        
    def check_data_freshness(self, max_hours_old=25):
        """Check if data is fresh enough for business needs"""
        with psycopg2.connect(self.connection_string) as conn:
            query = """
            SELECT 
                MAX(order_date) as latest_order_date,
                EXTRACT(HOURS FROM CURRENT_TIMESTAMP - MAX(order_date)) as hours_old
            FROM orders
            """
            df = pd.read_sql(query, conn)
            
            hours_old = float(df['hours_old'].iloc[0])
            latest_date = df['latest_order_date'].iloc[0]
            
            if hours_old > max_hours_old:
                return {
                    'status': 'ALERT',
                    'message': f'Data is {hours_old:.1f} hours old. Latest order: {latest_date}',
                    'metric': 'data_freshness',
                    'value': hours_old
                }
            else:
                return {
                    'status': 'OK',
                    'message': f'Data is fresh: {hours_old:.1f} hours old',
                    'metric': 'data_freshness',
                    'value': hours_old
                }
    
    def check_revenue_anomalies(self):
        """Detect unusual revenue patterns that might indicate data issues"""
        with psycopg2.connect(self.connection_string) as conn:
            query = """
            WITH recent_revenue AS (
                SELECT 
                    DATE(order_date) as order_date,
                    SUM(revenue) as daily_revenue
                FROM fact_order_items 
                WHERE order_date >= CURRENT_DATE - INTERVAL '30 days'
                GROUP BY DATE(order_date)
                ORDER BY order_date
            ),
            revenue_stats AS (
                SELECT 
                    AVG(daily_revenue) as avg_revenue,
                    STDDEV(daily_revenue) as stddev_revenue
                FROM recent_revenue
            )
            SELECT 
                rr.order_date,
                rr.daily_revenue,
                rs.avg_revenue,
                rs.stddev_revenue,
                ABS(rr.daily_revenue - rs.avg_revenue) / rs.stddev_revenue as z_score
            FROM recent_revenue rr
            CROSS JOIN revenue_stats rs
            WHERE rr.order_date = CURRENT_DATE - INTERVAL '1 day'
            """
            
            df = pd.read_sql(query, conn)
            
            if df.empty:
                return {
                    'status': 'ALERT',
                    'message': 'No revenue data found for yesterday',
                    'metric': 'revenue_anomaly',
                    'value': 0
                }
            
            z_score = float(df['z_score'].iloc[0])
            daily_revenue = float(df['daily_revenue'].iloc[0])
            
            if abs(z_score) > 3:  # More than 3 standard deviations from mean
                return {
                    'status': 'ALERT',
                    'message': f'Revenue anomaly detected: ${daily_revenue:,.2f} (z-score: {z_score:.2f})',
                    'metric': 'revenue_anomaly',
                    'value': z_score
                }
            else:
                return {
                    'status': 'OK',
                    'message': f'Revenue within normal range: ${daily_revenue:,.2f}',
                    'metric': 'revenue_anomaly',
                    'value': z_score
                }
    
    def generate_pipeline_report(self):
        """Generate comprehensive pipeline health report"""
        checks = [
            self.check_data_freshness(),
            self.check_revenue_anomalies()
        ]
        
        alerts = [check for check in checks if check['status'] == 'ALERT']
        
        report = {
            'timestamp': datetime.now(),
            'total_checks': len(checks),
            'alerts': len(alerts),
            'status': 'HEALTHY' if len(alerts) == 0 else 'ISSUES_DETECTED',
            'details': checks
        }
        
        return report
```
