What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of machine learning where an agent learns to make decisions by interacting with an environment. The agent receives rewards or penalties based on its actions and learns to maximize cumulative reward over time.

Core Components

  • Agent - The learner/decision maker
  • Environment - The world the agent interacts with
  • State (s) - Current situation
  • Action (a) - What the agent can do
  • Reward (r) - Feedback signal
  • Policy (π) - Agent's strategy

The RL Loop

Exploration vs Exploitation

The fundamental dilemma in RL:

Exploration

Try new actions to discover potentially better rewards

Exploitation

Use known good actions to maximize current reward

Return (G): Total discounted reward from time t
Gt = rt+1 + γrt+2 + γ²rt+3 + ... = Σk=0∞ γkrt+k+1

γ (gamma): Discount factor (0 ≤ γ ≤ 1) - determines how much we value future rewards

Markov Decision Process (MDP)

An MDP is defined by the tuple (S, A, P, R, γ): States, Actions, Transition Probabilities, Rewards, and Discount Factor. The Markov Property states that the future depends only on the current state, not on history.

Bellman Equation

State-Value Function:
Vπ(s) = Σa π(a|s) Σs',r p(s',r|s,a)[r + γVπ(s')]

Action-Value Function:
Qπ(s,a) = Σs',r p(s',r|s,a)[r + γ Σa' π(a'|s')Qπ(s',a')]

Optimal Value (Bellman Optimality):
V*(s) = maxa Σs',r p(s',r|s,a)[r + γV*(s')]

The Bellman equations express the value of a state in terms of the values of successor states - this recursive relationship is the foundation of most RL algorithms.

Dynamic Programming

Dynamic Programming methods solve MDPs when we have a complete model of the environment. They use the Bellman equations to iteratively compute optimal value functions and policies.

Monte Carlo Methods

Monte Carlo methods learn from complete episodes of experience. They don't require a model of the environment - instead, they estimate values by averaging actual returns from sampled episodes.

How Monte Carlo Works

First-Visit MC:
V(s) ← average of returns following first visits to s

Every-Visit MC:
V(s) ← average of returns following all visits to s

Incremental Update:
V(s) ← V(s) + α[Gt - V(s)]

Advantages

  • No model required (model-free)
  • Can focus on interesting states
  • Simple to understand and implement

Disadvantages

  • Must wait for episode to end
  • High variance in estimates
  • Only for episodic tasks

Temporal Difference (TD) Learning

TD learning combines ideas from Monte Carlo and Dynamic Programming. It learns from incomplete episodes by bootstrapping - updating estimates based on other estimates.

Q-Learning

Q-Learning is an off-policy TD control algorithm. It learns the optimal Q-function directly by using the max operator, regardless of what policy the agent is following (behavior policy).

Q-Learning Update:
Q(s,a) ← Q(s,a) + α[r + γ maxa'Q(s',a') - Q(s,a)]

Key insight: Uses max over next state's Q-values (off-policy)
ε-greedy Policy: With probability ε, take random action (explore). Otherwise, take action with highest Q-value (exploit).

SARSA (State-Action-Reward-State-Action)

SARSA is an on-policy TD control algorithm. Unlike Q-Learning, it uses the action actually taken in the next state (following the same policy) rather than the max action.

1. Experience Replay

Store transitions (s, a, r, s') in a buffer and sample random mini-batches for training. Breaks correlation between consecutive samples.

2. Target Network

Use a separate network (θ⁻) for computing targets. Updated periodically to reduce oscillations.

DQN Loss:
L(θ) = E[(r + γ maxa'Q(s',a';θ⁻) - Q(s,a;θ))²]

θ: Online network parameters
θ⁻: Target network parameters (updated periodically)
