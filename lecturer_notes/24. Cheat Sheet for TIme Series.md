# 📘 Chronological Time Series Forecasting Guide

---

## **1️⃣ AR (AutoRegressive) vs MA (Moving Average) Models**

### 🔹 AR Model

**Idea:** The current value depends on **past values** of the series.

$$
y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \dots + \phi_p y_{t-p} + \epsilon_t
$$

* $c$: constant term
* $\phi_i$: autoregressive coefficients
* $\epsilon_t$: white noise

🧠 *Interpretation:* “Today’s value depends on previous values.”

---

### 🔹 MA Model

**Idea:** The current value depends on **past forecast errors (shocks)**.

$$
y_t = c + \epsilon_t + \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + \dots + \theta_q \epsilon_{t-q}
$$

* $\theta_i$: moving average coefficients
* $\epsilon_t$: random shocks

🧠 *Interpretation:* “Today’s value is influenced by recent random events.”

---

### 🔹 Comparison Summary

| Feature     | AR Model            | MA Model         |
| ----------- | ------------------- | ---------------- |
| Depends on  | Past values         | Past errors      |
| Captures    | Momentum / trends   | Short-term noise |
| Memory      | Long-term           | Short-term       |
| Typical use | Persistent patterns | Sudden shocks    |
| Stationary? | Requires            | Usually is       |

Combined model: **ARMA(p, q)**.

---

## **2️⃣ The Error Term $\epsilon_{t-1}$**

In any model,
$$
\epsilon_t = y_t - \hat{y}_t
$$

So the **previous period’s residual** is:
$$
\epsilon_{t-1} = y_{t-1} - \hat{y}_{t-1}
$$

In an MA(1) model:
$$
y_t = c + \epsilon_t + \theta_1 \epsilon_{t-1}
$$

* We only use *known* past residuals (from model fit).
* When forecasting future values, we assume future residuals = 0.

## **3️⃣ Autocorrelation vs Partial Autocorrelation**

### 🔹 Autocorrelation (ACF)

Correlation between $y_t$ and $y_{t-k}$.

$$
\rho_k = \text{Corr}(y_t, y_{t-k})
$$

* Shows overall dependency structure.
* Used to identify MA(q) order.

### 🔹 Partial Autocorrelation (PACF)

Correlation between $y_t$ and $y_{t-k}$ **after removing effects** of shorter lags.

$$
\phi_{kk} = \text{Corr}(y_t, y_{t-k} \mid y_{t-1}, ..., y_{t-(k-1)})
$$

* Captures *direct* relationships.
* Used to identify AR(p) order.

---

### 🔹 Diagnostic Rule of Thumb

| Model     | ACF                  | PACF                 |
| --------- | -------------------- | -------------------- |
| AR(p)     | Tails off            | Cuts off after lag p |
| MA(q)     | Cuts off after lag q | Tails off            |
| ARMA(p,q) | Both tail off        | Both tail off        |

## **4️⃣ Time Series Decomposition**

Decomposition separates a time series into interpretable parts:

$$
y_t = T_t + S_t + R_t \quad \text{(Additive)}
$$
or
$$
y_t = T_t \times S_t \times R_t \quad \text{(Multiplicative)}
$$

Where:

* $T_t$: **Trend** — long-term movement
* $S_t$: **Seasonality** — repeating pattern
* $R_t$: **Residual** — random noise

---

### 🔹 Additive Model

Used when seasonal variation is **constant** across time.

$$
y_t = T_t + S_t + R_t
$$

### 🔹 Multiplicative Model

Used when seasonal variation **changes with trend**.

$$
y_t = T_t \times S_t \times R_t
$$
or equivalently:
$$
\log(y_t) = \log(T_t) + \log(S_t) + \log(R_t)
$$

---

### 🔹 Estimating Components

**Trend (T):**
Use a centered moving average or regression.

$$
T_t = \frac{1}{2m+1} \sum_{i=-m}^{m} y_{t+i}
$$

**Seasonality (S):**
Subtract or divide by trend, then average by period.

$$
S_k = \frac{1}{N_k} \sum_{t \in k} (y_t - T_t)
$$
(Additive)

or
$$
S_k = \frac{1}{N_k} \sum_{t \in k} \frac{y_t}{T_t}
$$
(Multiplicative)

**Residual (R):**
$$
R_t = y_t - T_t - S_t \quad \text{or} \quad R_t = \frac{y_t}{T_t S_t}
$$

---

### 🔹 Small Numeric Example (Additive)

| Quarter | $y_t$ | $T_t$ | $S_t$ | $R_t$ |
| ------- | ------- | ------- | ------- | ------- |
| Q1      | 130     | 137.5   | −10.0   | 2.5     |
| Q2      | 145     | 140.0   | 2.5     | 2.5     |
| Q3      | 160     | 142.5   | 15.0    | 2.5     |
| Q4      | 130     | 135.0   | −7.5    | 2.5     |

## **5️⃣ Using Decomposition for Forecasting**

Forecasting formula (additive):
$$
\hat{y}*{t+h} = \hat{T}*{t+h} + \hat{S}*{t+h} + \hat{R}*{t+h}
$$

Steps:

1. **Trend** → Extend via regression or extrapolation
2. **Seasonality** → Repeat seasonal indices
3. **Residual** → Usually set to 0 or modeled via ARIMA

Example:

| Quarter | Trend | Season | Forecast |
| ------- | ----- | ------ | -------- |
| Q1      | 145   | −10    | 135      |
| Q2      | 147   | 2.5    | 149.5    |
| Q3      | 149   | 15     | 164      |
| Q4      | 151   | −7.5   | 143.5    |

## **6️⃣ Unit Root and Stationarity**

### 🔹 AR(1) Process:

$$
y_t = \phi y_{t-1} + \epsilon_t
$$

If $|\phi| < 1$ → **stationary**
If $\phi = 1$ → **unit root (random walk)**
If $\phi > 1$ → **explosive**

Random walk:
$$
y_t = y_{t-1} + \epsilon_t
$$
or
$$
\Delta y_t = \epsilon_t
$$

### 🔹 Implications

* Non-stationary: variance grows with time.
* Shocks have *permanent* effects.
* Remedy: **difference the series**.

$$
\Delta y_t = y_t - y_{t-1}
$$

### 🔹 Unit Root Tests

| Test | Null Hypothesis | Alternate     |
| ---- | --------------- | ------------- |
| ADF  | Has unit root   | Stationary    |
| PP   | Has unit root   | Stationary    |
| KPSS | Stationary      | Has unit root |

---

### 🔹 Variance Behavior

| Type             | Variance Behavior                     |
| ---------------- | ------------------------------------- |
| Stationary AR(1) | Constant variance                     |
| Unit Root        | Variance increases linearly with time |

## **7️⃣ Prophet Model (Facebook/Meta)**

Prophet is an **additive forecasting model**:

$$
y(t) = g(t) + s(t) + h(t) + \varepsilon_t
$$

Where:

* $g(t)$: **Trend** — linear or logistic growth
* $s(t)$: **Seasonality** — via Fourier series
* $h(t)$: **Holidays / events**
* $\varepsilon_t$: **Noise**

### 🔹 Components

| Component         | Description                       | Example                 |
| ----------------- | --------------------------------- | ----------------------- |
| $g(t)$          | Trend (piecewise linear/logistic) | Long-term growth        |
| $s(t)$          | Seasonality (Fourier terms)       | Weekly/yearly cycles    |
| $h(t)$          | Holidays                          | Christmas, promotions   |
| $\varepsilon_t$ | Random noise                      | Unpredictable variation |

### 🔹 Example Code

```python
from prophet import Prophet
m = Prophet(yearly_seasonality=True, weekly_seasonality=True)
m.fit(df)
future = m.make_future_dataframe(periods=12, freq='M')
forecast = m.predict(future)
m.plot(forecast)
m.plot_components(forecast)
```

### 🔹 Comparison with ARIMA

| Feature        | Prophet             | ARIMA                   |
| -------------- | ------------------- | ----------------------- |
| Trend          | Flexible, nonlinear | Differencing removes it |
| Seasonality    | Fourier series      | Seasonal AR/MA terms    |
| Holidays       | Built-in            | Manual dummy vars       |
| Ease           | High                | Moderate                |
| Interpretation | Very high           | Medium                  |
